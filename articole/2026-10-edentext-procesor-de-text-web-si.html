EdenText: Procesor de text web și desktop pentru fișiere DOCX și ODT — Open Source, Local-First și Private by Design

Multe dintre alternativele moderne la Microsoft Word care rulează în browser (cum ar fi Google Docs sau variantele clasice bazate pe server precum Nextcloud Hub / ONLYOFFICE Docs) depind în totalitate de o infrastructură backend care găzduiește și procesează documentele pe servere la distanță.

Proiectul open-source EdenText (creat de dezvoltatorul german Steffen Becker / @stffnb) schimbă această paradigmă: oferă un procesor de text complet funcțional, capabil să citească și să scrie nativ formate .docx și .odt, care rulează în întregime pe partea de client (local-first). Documentele nu părăsesc niciodată calculatorul utilizatorului, funcționând fără cont, fără server de procesare și complet offline.

1. Arhitectură tehnică modernă: Svelte 5, TipTap 3 și Zero-Backend

Spre deosebire de monoliții clasici compilați sau serverele greoaie de randare, EdenText este construit pe o stivă web modernă și modulară:

  • Framework & Frontend: Construit cu Svelte 5, TypeScript și Vite.

  • Motor de redactare: Folosește TipTap 3 (bazat pe arhitectura robustă a nucleului ProseMirror).

  • Amprentă minimă de rețea: La prima încărcare, aplicația descarcă doar aproximativ 2 MB comprimați (codul de bază având sub 1 MB), adăugând fonturile și dicționarele doar la cerere și stocându-le local pentru sesiuni ulterioare fără conexiune la internet.

  • Recuperare locală a datelor: Browserul păstrează automat în localStorage ultimele trei versiuni ale documentului deschis, prevenind pierderile accidentale în cazul închiderii ferestrei sau al blocajelor.

2. Capabilități avansate de machetare și tehnoredactare academică

EdenText nu este un simplu editor Markdown mascat, ci oferă o randare vizuală pe pagină reală (real page layout), comparabilă cu software-urile desktop mature:

CategorieFuncționalități suportate
Machetare paginăFormate A4/Letter, margini oglindite (mirrored margins) pentru cărți, capitole care încep obligatoriu pe pagina din dreapta, anteturi și subsoluri personalizate, note de subsol (footnotes), coloane multiple și filigrane (watermarks).
Stiluri & StructurăStiluri ierarhice de paragraf, caracter, tabel și listă cu moștenire; numerotare automată a capitolelor și repornirea numerotării paginilor după paginația introductivă.
Instrumente academiceCuprins automat (Table of Contents), legende de imagini (captions), referințe încrucișate (cross-references), bibliografie și citări, index alfabetic și formule matematice complexe randate prin sintaxă LaTeX.
Tabele avansateTabele stilizate, sortare a celulelor și calcule automate prin formule matematice în stil foaie de calcul (spreadsheet formulas).
Colaborare & CorecturăUrmărirea modificărilor (Track Changes), comentarii în lanț afișate în baloane pe margine, verificare ortografică offline (în 8 limbi), sinonime și verificare gramaticală pentru limba engleză.

3. Asistent AI opțional și integrare locală

Aplicația include un asistent opțional de inteligență artificială, dezactivat în mod implicit:

  • Fără server intermediar: Solicitările nu trec printr-un server gestionat de EdenText, ci merg direct la furnizorul ales de utilizator.

  • Modele locale (Ollama): Poate fi conectat direct la o instanță locală Ollama sau la orice API compatibil OpenAI.

  • Control strict prin Track Changes: Asistentul poate răspunde la întrebări despre conținut sau poate aduce modificări textului, însă orice rescriere propusă este marcată automat ca modificare urmărită (tracked change), putând fi revizuită și acceptată manual de autor.

4. Metode de utilizare și autogăzduire (Self-Hosting)

EdenText este licențiat liber sub AGPL-3.0 și pune la dispoziție trei moduri de implementare:

A. Direct în Browser (Web App)

Accesibil la edentext.app sau instalabil ca PWA (Progressive Web App) cu pornire offline. În navigatoarele bazate pe Chromium (Chrome, Edge sau Brave cu flag-ul File System Access activat), butonul Save rescrie direct fișierul original de pe disc.

B. Aplicații Desktop Nativ (Electron)

Lansările oficiale includ pachete de sine stătătoare ce oferă dialoguri directe de scriere pe disc și export direct în PDF:

  • Linux: Imagine portabilă .AppImage și pachet .deb pentru Debian/Ubuntu:

    Bash
    chmod +x EdenText-*.AppImage
./EdenText-*.AppImage

  • macOS: Imagini .dmg pentru Apple Silicon și Intel.

  • Windows: Fișier de instalare .exe.

C. Autogăzduire prin container Docker

Deoarece aplicația este exclusiv client-side și nu menține o stare pe server, imaginea Docker servește pur și simplu fișierele statice:

Bash
docker run -d -p 8080:80 --name edentext ghcr.io/stffnb/edentext

Interfața devine disponibilă imediat la http://localhost:8080.
