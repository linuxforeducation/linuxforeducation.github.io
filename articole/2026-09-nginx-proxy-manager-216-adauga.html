Nginx Proxy Manager 2.16 adaugă vizualizator de loguri integrat direct în interfața Web

Proiectul open-source Nginx Proxy Manager a primit o actualizare majoră prin lansarea versiunii 2.16. Această versiune aduce o funcționalitate extrem de solicitată de comunitate: un vizualizator de loguri încorporat nativ în interfața grafică, eliminând necesitatea de a accesa terminalul sau de a folosi instrumente externe pentru inspecția traficului.

Cele mai importante noutăți din Nginx Proxy Manager 2.16

  • Vizualizator de loguri integrat (Built-in Log Viewer): Permite utilizatorilor să vizualizeze fișierele de acces (access logs) și cele de erori (error logs) direct din panoul de administrare Web pentru fiecare host configurat în parte.

  • Depanare rapidă în timp real: Simplifică semnificativ identificarea erorilor de redirecționare, a problemelor cu certificatele SSL/TLS sau a cererilor blocate, fără conexiuni SSH pe server.

  • Optimizări ale interfeței și performanței:

    • Îmbunătățiri ale timpului de răspuns pentru panoul de control la gestionarea unui număr mare de proxy hosts.

    • Reorganizare vizuală minoră pentru secțiunile de configurare a certificatelor Let's Encrypt și a listelor de acces (ACL).

  • Actualizări ale stivei de pachete: Actualizarea versiunilor interne de Node.js și Nginx folosite în containerul Docker pentru rezolvarea vulnerabilităților cunoscute și îmbunătățirea stabilității.

De ce este un plus semnificativ pentru Homelab-uri și Self-Hosters?

Nginx Proxy Manager este una dintre cele mai populare soluții grafice de tip reverse proxy folosite în mediile Docker. Până la această versiune, inspectarea logurilor necesita fie rularea comenzii docker logs, fie montarea directoarelor de loguri într-o aplicație terță (cum ar fi Dozzle sau stive ELK).
