DavMail 7.0: Sincronizare mai rapidă pentru Microsoft 365 și Exchange

Proiectul open-source DavMail a lansat versiunea 7.0, aducând îmbunătățiri semnificative de performanță și stabilitate pentru conectarea clienților standard de e-mail/calendar (precum Thunderbird) la serverele Microsoft Exchange și serviciile Microsoft 365 [source: 1].

Noutățile principale din DavMail 7.0

1. Sincronizare IMAP optimizată (Folder Delta Sync)

  • A fost implementat un sistem de sincronizare bazat pe delta sync cu cache [source: 1].

  • În loc să reîcarce întregul conținut al unui dosar la fiecare verificare, DavMail procesează doar modificările apărute între ciclurile de sincronizare, reducând drastic timpul de așteptare și consumul de resurse [source: 1].

2. Fiabilitate sporită pentru Microsoft Graph API

  • S-a îmbunătățit stabilitatea conexiunilor prin Microsoft Graph API [source: 1].

  • Include o gestionare mai eficientă a reîncercărilor (retry mechanism) atunci când Microsoft limitează/trunchiază cererile (throttling), precum și optimizări la reconstrucția cererilor eșuate [source: 1].

3. Îmbunătățiri pentru Calendare și Contacte (CalDAV / EWS)

  • Listele de distribuție: Adăugarea suportului complet pentru liste de distribuție [source: 1].

  • Evenimente recurente: Gestionare îmbunătățită a răspunsurilor pentru fiecare instanță/ocurență a unei ședințe [source: 1].

  • Relucrarea backend-ului EWS: Ajustări majore privind organizatorii, participanții, calendarele partajate și excepțiile de la evenimentele repetitiv-recurente [source: 1].

  • Mod Read-Only: O nouă opțiune davmail.caldavReadonly le permite utilizatorilor să seteze calendarele expuse prin CalDAV în mod doar-citire [source: 1].

  • Alte corecții: Rezolvări legate de fusul orar (timezones) și maparea numerelor de telefon [source: 1].
