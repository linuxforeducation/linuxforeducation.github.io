Manual de administrare Debian Linux

Ghid complet în limba română pentru instalarea, configurarea și administrarea sistemului Debian, de la bazele terminalului până la servicii web și securitate.

1. Introducere în Debian

Debian este una dintre cele mai vechi și mai stabile distribuții Linux, lansată pentru prima dată în 1993 de Ian Murdock. Renumit pentru fiabilitate, securitate și respectarea standardelor software libere, Debian stă la baza multor alte distribuții populare, inclusiv Ubuntu.

Debian 12 "Bookworm", lansat în 2023, include kernel Linux 6.1 LTS, suport îmbunătățit pentru firmware proprietar și pachete actualizate. Sistemul de release urmează un ciclu de aproximativ 2 ani, cu ramurile stable, testing și unstable.

Ramurile Debian

RamurăNumeDescriereRecomandare
stableBookwormPachete testate, maxim stabileProducție / servere
testingTrixieViitoarea versiune stabilăDesktop avansat
unstableSidCele mai noi pachete, mai puțin testateDezvoltatori
backports—Pachete noi retroportate pe stablePachete specifice noi

Filozofia Debian

Debian urmează Contractul Social Debian și Ghidul Debian pentru Software Liber (DFSG). Distribuția este condusă de voluntari și nu este deținută de nicio companie. Pachetele sunt împărțite în trei secțiuni: main (100% liber), contrib (liber, dar depinde de non-free) și non-free (software proprietar).

2. Instalarea Sistemului

Debian oferă mai multe imagini de instalare: netinst (~400MB, descarcă pachetele din internet), DVD (offline complet) și live (testare fără instalare). Pentru servere, netinst este opțiunea recomandată.

Descărcarea imaginii

bash — verificare integritate ISO
# Descarcă imaginea netinst (amd64)
wget https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-12.x.x-amd64-netinst.iso

# Verifică suma de control SHA512
sha512sum -c SHA512SUMS 2>/dev/null | grep debian-12

Crearea unui USB bootabil

bash — scriere pe USB (Linux/macOS)
# Identifică dispozitivul USB (atenție la litera corectă!)
lsblk

# Scrie imaginea — ÎNLOCUIEȘTE /dev/sdX cu dispozitivul tău
sudo dd if=debian-12-amd64-netinst.iso of=/dev/sdX bs=4M status=progress conv=fsync
sudo sync

⚠ Atenție Comanda dd va șterge irevocabil toate datele de pe dispozitivul țintă. Verifică de două ori că ai selectat USB-ul și nu discul sistemului tău!

Configurare post-instalare esențială

bash — primii pași după instalare
# Actualizează lista de pachete și sistemul
apt update && apt full-upgrade -y

# Instalează unelte esențiale
apt install -y sudo curl wget git vim htop net-tools lsof

# Adaugă utilizatorul tău în grupul sudo
usermod -aG sudo numeutilizator

# Setează hostname-ul
hostnamectl set-hostname debian-server

3. Gestionarea Pachetelor

Debian folosește sistemul de pachete .deb cu instrumentele apt (interfață de nivel înalt) și dpkg (nivel jos). APT rezolvă automat dependențele și descarcă pachetele din depozite (repositories).

Comenzi esențiale APT

bash — gestionare pachete cu apt
# Actualizează indexul de pachete
apt update

# Actualizează pachetele instalate
apt upgrade

# Actualizare completă (inclusiv schimbări de dependențe)
apt full-upgrade

# Instalează un pachet
apt install nginx

# Dezinstalează (păstrează configurația)
apt remove nginx

# Dezinstalează complet (șterge și configurația)
apt purge nginx

# Curăță pachete neutilizate
apt autoremove

# Caută un pachet
apt search "web server"

# Informații despre un pachet
apt show nginx

# Listează pachetele instalate
apt list --installed

Fișierul sources.list

/etc/apt/sources.list — configurare depozite Debian 12
deb http://deb.debian.org/debian bookworm main contrib non-free non-free-firmware
deb http://deb.debian.org/debian bookworm-updates main contrib non-free non-free-firmware
deb http://security.debian.org/debian-security bookworm-security main contrib non-free non-free-firmware

# Backports (pachete mai noi retroportate)
deb http://deb.debian.org/debian bookworm-backports main contrib non-free

Lucrul cu dpkg

bash — dpkg pentru operații de nivel jos
# Instalează un .deb local
dpkg -i pachet.deb

# Listează toate pachetele instalate
dpkg -l

# Verifică dacă un pachet este instalat
dpkg -l nginx

# Listează fișierele unui pachet
dpkg -L nginx

# Află cărui pachet îi aparține un fișier
dpkg -S /usr/sbin/nginx

# Reconfigurează un pachet
dpkg-reconfigure tzdata

💡 Sfat Folosește apt-cache depends pachet pentru a vedea dependențele unui pachet înainte de instalare, și apt-cache rdepends pachet pentru a vedea ce pachete depind de el.

4. Configurarea Rețelei

Debian 12 folosește în principal systemd-networkd sau fișierul tradițional /etc/network/interfaces pentru configurarea rețelei. Pe sisteme desktop, NetworkManager este preferat.

Configurare cu /etc/network/interfaces

/etc/network/interfaces — configurare statică
source /etc/network/interfaces.d/*

auto lo
iface lo inet loopback

# Interfață cu IP static
auto eth0
iface eth0 inet static
    address 192.168.1.100/24
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 1.1.1.1

# Interfață cu DHCP
# auto eth0
# iface eth0 inet dhcp

Instrumente de rețea

bash — diagnosticare rețea
# Afișează interfețele și adresele IP (modern)
ip addr show
ip a

# Afișează tabela de rutare
ip route show

# Testează conectivitate
ping -c 4 8.8.8.8

# Rezolvare DNS
dig google.com
nslookup google.com

# Statistici conexiuni rețea
ss -tuln          # conexiuni TCP/UDP active
ss -tulnp         # cu PID-uri

# Traseu pachete
traceroute 8.8.8.8

# Scanare porturi locale
nmap localhost

# Repornire serviciu rețea
systemctl restart networking

Configurare firewall cu nftables

bash — firewall de bază cu nftables
# Instalează nftables
apt install nftables

# Editează regulile
nano /etc/nftables.conf

# Configurare de bază (în /etc/nftables.conf):
# table inet filter {
#   chain input {
#     type filter hook input priority 0; policy drop;
#     iif lo accept
#     ct state established,related accept
#     tcp dport { ssh, http, https } accept
#     icmp type echo-request accept
#   }
#   chain forward { type filter hook forward priority 0; policy drop; }
#   chain output  { type filter hook output priority 0; policy accept; }
# }

systemctl enable --now nftables
nft list ruleset

5. Administrarea Utilizatorilor

Linux folosește un model de permisiuni bazat pe utilizatori și grupuri. Fiecare fișier are un proprietar (user), un grup și permisiuni pentru others. Contul root are acces nelimitat la sistem.

Gestiunea utilizatorilor

bash — creare și modificare utilizatori
# Creează un utilizator nou cu director home
useradd -m -s /bin/bash -c "Nume Complet" username

# Setează parola
passwd username

# Modifică utilizatorul (exemplu: schimbă shell-ul)
usermod -s /bin/zsh username

# Adaugă în grup suplimentar
usermod -aG sudo,docker username

# Șterge utilizatorul (și directorul home cu -r)
userdel -r username

# Blochează/deblochează un cont
passwd -l username    # blochează
passwd -u username    # deblochează

# Informații despre utilizator
id username
getent passwd username

Gestiunea grupurilor

bash — grupuri Linux
# Creează grup nou
groupadd devteam

# Adaugă utilizator în grup
gpasswd -a username devteam
# sau
usermod -aG devteam username

# Elimină utilizatorul din grup
gpasswd -d username devteam

# Listează membrii unui grup
getent group devteam

# Listează grupurile unui utilizator
groups username
id username

Permisiuni și chmod

bash — permisiuni fișiere și directoare
# Sintaxa permisiunilor: rwxrwxrwx (user/group/others)
# r=4, w=2, x=1

# Setează permisiunile numeric
chmod 644 fisier.txt       # rw-r--r--
chmod 755 script.sh        # rwxr-xr-x
chmod 700 director_privat  # rwx------

# Setează permisiunile simbolic
chmod u+x script.sh        # adaugă execute pentru user
chmod go-w fisier.txt      # elimină write pentru group/others
chmod a+r fisier.txt       # citire pentru toți

# Schimbă proprietarul
chown user:group fisier.txt
chown -R www-data:www-data /var/www/html

# Verifică permisiunile
ls -la /var/www/html

sudo — privilegii de root

bash — configurare sudo
# Editează configurația sudo (mereu cu visudo!)
visudo

# Exemplu intrare în /etc/sudoers:
# username ALL=(ALL:ALL) ALL
# sau fără parolă:
# username ALL=(ALL) NOPASSWD: ALL

# Grup sudo (Debian) are acces complet implicit
usermod -aG sudo username

# Execută o comandă ca root
sudo apt update
sudo -i          # deschide shell root complet
sudo -u altuser comandă  # rulează ca alt utilizator

6. Comenzi Esențiale de Terminal

Stăpânirea terminalului este esențială pentru orice administrator Debian. Comenzile de mai jos acoperă navigarea, manipularea fișierelor, căutarea, procesarea textului și monitorizarea sistemului.

Navigare și fișiere

bash — navigare și gestiune fișiere
# Navigare
pwd                        # directorul curent
cd /var/log                # schimbă directorul
cd ~                       # mergi la home
cd -                       # directorul anterior

# Listare
ls -lah                    # listare detaliată + hidden + human-readable
ls -lt                     # sortare după dată modificare
tree -L 2                  # arbore directoare, adâncime 2

# Creare
mkdir -p /opt/app/logs     # creare directoare recursive
touch fisier.txt           # creează fișier gol / actualizează timestamp

# Copiere / mutare
cp -r /sursa /destinatie   # copiere recursivă
mv fisier.txt /tmp/        # mută / redenumește
rsync -avz src/ dest/      # sincronizare eficientă

# Ștergere (cu atenție!)
rm fisier.txt              # șterge fișier
rm -rf /tmp/director       # șterge recursiv (periculos!)

# Legătari simbolice
ln -s /usr/bin/python3 /usr/local/bin/python

Căutare și procesare text

bash — find, grep, sed, awk
# find — caută fișiere
find /var/log -name "*.log" -mtime -7      # modificate în ultimele 7 zile
find /home -type f -size +100M             # fișiere mai mari de 100MB
find /etc -name "*.conf" -exec ls -la {} \;

# grep — caută în conținut
grep -r "error" /var/log/                  # recursiv
grep -n "failed" /var/log/auth.log         # cu numărul liniei
grep -v "^#" /etc/fstab                    # inversează (exclude comentariile)
grep -E "ERROR|WARN" app.log              # expresii regulate (extended)

# sed — substituire text
sed 's/vechi/nou/g' fisier.txt             # înlocuire globală (output)
sed -i 's/vechi/nou/g' fisier.txt          # înlocuire in-place
sed '/^#/d' fisier.conf                    # șterge liniile comentariu

# awk — procesare coloane
awk '{print $1, $3}' fisier.txt            # afișează coloanele 1 și 3
awk -F: '{print $1}' /etc/passwd           # listează utilizatorii
df -h | awk 'NR>1 {print $5, $6}'         # utilizare disk

Monitorizarea sistemului

bash — resurse și procese
# Procese
ps aux                     # toate procesele
ps aux | grep nginx        # filtrează după nume
top                        # monitor interactiv
htop                       # monitor avansat (apt install htop)
kill -9 PID                # forțează oprirea unui proces
pkill -f "nume_proces"     # oprire după nume

# Memorie și CPU
free -h                    # utilizare memorie (human-readable)
vmstat 1 5                 # statistici la fiecare secundă, de 5 ori
uptime                     # timp funcționare + load average
lscpu                      # informații CPU

# Spațiu pe disk
df -h                      # utilizare partiții
du -sh /var/log/*          # dimensiunea fiecărui director
ncdu /                     # navigator interactiv (apt install ncdu)

# I/O disk
iostat -x 1                # statistici I/O
iotop                      # monitorizare I/O pe procese

7. Securitate

Securizarea unui sistem Debian implică actualizări regulate, configurarea corectă a SSH, folosirea unui firewall și monitorizarea activității. Un sistem securizat aplică principiul least privilege — fiecare serviciu rulează cu permisiunile minime necesare.

Actualizări de securitate automate

bash — actualizări automate nesupravegheat
# Instalează unattended-upgrades
apt install unattended-upgrades apt-listchanges

# Configurează
dpkg-reconfigure -plow unattended-upgrades

# Editează configurația
nano /etc/apt/apt.conf.d/50unattended-upgrades

# Activare actualizări zilnice
nano /etc/apt/apt.conf.d/20auto-upgrades
# Conținut:
# APT::Periodic::Update-Package-Lists "1";
# APT::Periodic::Unattended-Upgrade "1";

# Verifică log-ul
cat /var/log/unattended-upgrades/unattended-upgrades.log

Securizarea SSH

/etc/ssh/sshd_config — configurare recomandată
# Schimbă portul implicit (optional, dar recomandat)
Port 2222

# Dezactivează autentificarea cu parolă (folosește chei SSH!)
PasswordAuthentication no
PubkeyAuthentication yes

# Dezactivează login-ul direct ca root
PermitRootLogin no

# Permite doar anumiți utilizatori
AllowUsers username altuser

# Dezactivează X11 forwarding dacă nu e necesar
X11Forwarding no

# Setează timeout inactivitate (în secunde)
ClientAliveInterval 300
ClientAliveCountMax 2

# Versiunea protocolului (doar SSH2)
Protocol 2

Generarea și configurarea cheilor SSH

bash — autentificare cu chei SSH
# Generează pereche de chei (pe calculatorul client)
ssh-keygen -t ed25519 -C "comentariu@email.ro"
# sau RSA pentru compatibilitate mai largă:
ssh-keygen -t rsa -b 4096

# Copiază cheia publică pe server
ssh-copy-id -i ~/.ssh/id_ed25519.pub user@server-ip

# Manual — adaugă cheia în authorized_keys
cat ~/.ssh/id_ed25519.pub >> ~/.ssh/authorized_keys
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys

# Verifică conectarea
ssh -i ~/.ssh/id_ed25519 user@server-ip

fail2ban — protecție brute-force

bash — instalare și configurare fail2ban
apt install fail2ban

# Creează configurație locală (nu edita .conf direct)
cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local

# Editează jail.local — setări de bază
nano /etc/fail2ban/jail.local
# [DEFAULT]
# bantime  = 1h
# findtime = 10m
# maxretry = 5
#
# [sshd]
# enabled = true
# port = 2222

systemctl enable --now fail2ban

# Statusul jail-urilor
fail2ban-client status
fail2ban-client status sshd

# Deblochează un IP
fail2ban-client set sshd unbanip 1.2.3.4

Verificare integritate cu AIDE

bash — sistem de detecție a intruziunilor
apt install aide

# Inițializează baza de date (după o instalare curată)
aideinit
mv /var/lib/aide/aide.db.new /var/lib/aide/aide.db

# Verifică modificările față de baseline
aide --check

# Programează verificare zilnică
# Cron-ul este adăugat automat la instalare

8. Servicii și Procese cu systemd

systemd este sistemul de init și manager de servicii utilizat de Debian. Înlocuiește SysVinit tradițional și oferă management paralel al serviciilor, logging integrat (journald) și gestionarea dependențelor între servicii.

Gestiunea serviciilor

bash — comenzi systemctl
# Pornire / oprire / repornire
systemctl start nginx
systemctl stop nginx
systemctl restart nginx
systemctl reload nginx        # reîncarcă configurația fără oprire

# Activare la boot
systemctl enable nginx
systemctl disable nginx
systemctl enable --now nginx  # activează ȘI pornește imediat

# Verificare stare
systemctl status nginx
systemctl is-active nginx
systemctl is-enabled nginx

# Listare servicii
systemctl list-units --type=service
systemctl list-units --type=service --state=failed

# Reîncarcă configurația systemd (după modificarea fișierelor .service)
systemctl daemon-reload

Crearea unui serviciu personalizat

/etc/systemd/system/myapp.service — unit file
[Unit]
Description=Aplicatia mea web
Documentation=https://example.com/docs
After=network.target postgresql.service
Requires=postgresql.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/opt/myapp
ExecStart=/opt/myapp/bin/server --port 8080
ExecReload=/bin/kill -HUP $MAINPID
Restart=on-failure
RestartSec=5
StandardOutput=journal
StandardError=journal

# Izolare (securitate)
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target

Journald — logging centralizat

bash — vizualizare log-uri cu journalctl
# Log-urile unui serviciu
journalctl -u nginx
journalctl -u nginx -f          # urmărire în timp real (follow)
journalctl -u nginx --since "1 hour ago"
journalctl -u nginx -n 50       # ultimele 50 de linii

# Log-urile sistemului
journalctl -b                   # boot-ul curent
journalctl -b -1                # boot-ul anterior
journalctl --since "2024-01-01" --until "2024-01-02"
journalctl -p err               # doar erorile (err/warning/info/debug)

# Curăță log-urile vechi
journalctl --vacuum-time=30d    # păstrează ultimele 30 zile
journalctl --vacuum-size=500M   # limitează la 500MB

9. Servicii Web, SSH și Baze de Date

Un server LAMP (Linux, Apache, MySQL, PHP) sau LEMP (cu Nginx) este una dintre cele mai comune configurații. Debian facilitează instalarea tuturor componentelor prin APT.

Apache — instalare și virtual hosts

bash — Apache2 pe Debian
apt install apache2

# Activează module esențiale
a2enmod rewrite ssl headers deflate

# Creează un virtual host
nano /etc/apache2/sites-available/exemplu.conf
/etc/apache2/sites-available/exemplu.conf
<VirtualHost *:80>
    ServerName exemplu.ro
    ServerAlias www.exemplu.ro
    DocumentRoot /var/www/exemplu

    <Directory /var/www/exemplu>
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog  ${APACHE_LOG_DIR}/exemplu-error.log
    CustomLog ${APACHE_LOG_DIR}/exemplu-access.log combined

    # Redirecționare la HTTPS
    Redirect permanent / https://exemplu.ro/
</VirtualHost>
bash — activare site Apache
a2ensite exemplu.conf
a2dissite 000-default.conf
apache2ctl configtest          # verifică sintaxa
systemctl reload apache2

Nginx — configurare de bază

/etc/nginx/sites-available/exemplu.conf
server {
    listen 80;
    server_name exemplu.ro www.exemplu.ro;
    root /var/www/exemplu;
    index index.html index.php;

    # Securitate headers
    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.ht {
        deny all;    # protejează .htaccess
    }
}

SSL cu Let's Encrypt / Certbot

bash — certificat SSL gratuit
apt install certbot python3-certbot-nginx

# Obține și instalează automat certificatul
certbot --nginx -d exemplu.ro -d www.exemplu.ro

# Sau doar obține certificatul (pentru configurare manuală)
certbot certonly --webroot -w /var/www/html -d exemplu.ro

# Testează reînnoirea automată
certbot renew --dry-run

# Certbot creează automat un cron/systemd timer pentru reînnoire

MySQL / MariaDB

bash — instalare și configurare MariaDB
apt install mariadb-server
mysql_secure_installation     # configurare inițială de securitate

# Conectare ca root
mysql -u root -p

# Comenzi SQL de bază:
# CREATE DATABASE myapp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
# CREATE USER 'appuser'@'localhost' IDENTIFIED BY 'parola_sigura';
# GRANT ALL PRIVILEGES ON myapp.* TO 'appuser'@'localhost';
# FLUSH PRIVILEGES;
# EXIT;

# Backup baza de date
mysqldump -u root -p myapp > backup_myapp_$(date +%Y%m%d).sql

# Restaurare din backup
mysql -u root -p myapp < backup_myapp_20240101.sql

10. Depanare și Diagnostic

Depanarea sistemelor Linux necesită o abordare sistematică: identifică simptomele, verifică log-urile, izolează componenta problematică și testează soluțiile. Instrumentele de mai jos acoperă cele mai frecvente scenarii.

Analiza log-urilor

bash — localizarea problemelor prin log-uri
# Log-uri principale pe Debian
/var/log/syslog              # mesaje generale sistem
/var/log/auth.log            # autentificări și sudo
/var/log/kern.log            # mesaje kernel
/var/log/dpkg.log            # operații APT/dpkg
/var/log/apache2/            # log-uri Apache
/var/log/nginx/              # log-uri Nginx
/var/log/mysql/              # log-uri MySQL/MariaDB

# Urmărire în timp real
tail -f /var/log/syslog
tail -f /var/log/auth.log

# Caută erori în log-uri
grep -i "error\|fail\|crit" /var/log/syslog | tail -50
journalctl -p err -b          # erori din boot-ul curent

# Mesaje kernel recente
dmesg | tail -30
dmesg | grep -i "error\|fail\|warn"

Diagnosticare spațiu pe disk

bash — probleme de spațiu
# Verifică utilizarea diskului
df -h

# Găsește directoarele mari
du -sh /* 2>/dev/null | sort -hr | head -10
du -sh /var/* | sort -hr | head -10

# Găsește fișierele mari
find / -type f -size +500M 2>/dev/null | sort -k 5 -n

# Curăță cache-ul APT
apt clean
apt autoclean

# Curăță log-uri journald vechi
journalctl --vacuum-time=7d

# Elimină pachete neutilizate
apt autoremove --purge

# Verifică inode-uri (altă cauză "disk full")
df -i

Diagnosticare servicii care nu pornesc

bash — debugging servicii systemd
# Verifică statusul detaliat
systemctl status nginx.service -l

# Log-urile serviciului
journalctl -u nginx --no-pager -n 100

# Verifică configurația (exemplu Nginx)
nginx -t

# Verifică ce proces ocupă un port
ss -tlnp | grep :80
lsof -i :80

# Repornire forțată
systemctl stop nginx
sleep 2
systemctl start nginx
systemctl status nginx

Probleme de boot

bash — diagnosticare boot și recovery
# Verifică timpul de boot și unele lente
systemd-analyze blame | head -20
