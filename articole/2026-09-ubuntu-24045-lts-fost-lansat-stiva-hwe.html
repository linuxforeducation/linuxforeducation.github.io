Ubuntu 24.04.5 LTS a fost lansat: Stiva HWE actualizată aduce kernelul Linux 7.0 și drivere grafice Mesa 26.2


Publicația Linuxiac detaliază lansarea Ubuntu 24.04.5 LTS (Noble Numbat), al cincilea și ultimul update de mentenanță programat pentru această serie Long-Term Support. Lansarea reîmprospătează imaginile ISO de instalare și include toate corecțiile de securitate acumulate în ultimele șase luni.

✨ Punctele cheie ale lansării Ubuntu 24.04.5 LTS:

🐧 Kernel Linux 7.0 prin stiva HWE:

• Versiunea Desktop beneficiază implicit de noua stivă de activare hardware (Hardware Enablement - HWE), aducând kernelul Linux 7.0 (înlocuind kernelul Linux 6.17 folosit de versiunea 24.04.4). Ediția Server păstrează implicit kernelul GA (General Availability) v6.8, oferind opțional activarea HWE.

🎮 Stivă grafică modernizată (Mesa 26.2):

• Include versiunea recentă Mesa 26.2, aducând performanțe sporite și suport mai bun pentru GPU-urile recente AMD și Intel în sesiunile de gaming și procesare grafică.

📦 Toate aromele oficiale (Flavors) actualizate simultan:

• Sunt disponibile noi imagini ISO pentru întreaga familie Ubuntu: Kubuntu, Xubuntu, Lubuntu, Ubuntu Budgie, Ubuntu MATE, Ubuntu Studio, Ubuntu Cinnamon, Edubuntu, Kylin și Ubuntu Unity.

🔄 Proces de actualizare facil:

• Utilizatorii existenți de Ubuntu 24.04 LTS nu trebuie să reinstaleze sistemul. Trecerea la 24.04.5 se realizează automat prin sistemul obișnuit de update (sudo apt update && sudo apt upgrade).

🔗 Sursă și articol complet:

https://linuxiac.com/ubuntu-24-04-5-lts-released-with-updated-hwe-stack/

📌 Concluzie:

Ubuntu 24.04.5 LTS reprezintă punctul culminant de maturitate pentru seria Noble Numbat, oferind o bază excelentă de instalare directă cu suport hardware de ultimă generație pentru utilizatorii care preferă un sistem LTS ultrastabil! 🚀
