Teku (anuzdhk/teku): Instalator universal de pachete Linux prin click-dreapta cu detectare automată de formate și distribuții

Dezvoltat de același autor din spatele proiectului TaskMonitor (anuzdhk / Little Systems) și publicat sub licența liberă GPL-3.0, Teku este un utilitar conceput pentru a elimina complet bariera comenzilor de terminal la instalarea pachetelor software descărcate manual pe Linux.

Motto-ul proiectului este simplu: „Install Linux apps from a right-click”. Teku inspectează fișierul selectat și metadatele distribuției curente, declanșează automat utilitarul nativ adecvat de pachete și instalează aplicația — sau explică într-un mod clar și prietenos de ce fișierul respectiv nu poate fi instalat.

Mecanism de funcționare: Detectare prin Magic Bytes și Zero Confuzie

Una dintre problemele frecvente întâmpinate de începători este descărcarea de fișiere destinate altor sisteme de operare sau încercarea de a instala pachete incompatibile cu distribuția curentă:

  • Detecție prin octeți magici (Magic Bytes): Teku nu se bazează exclusiv pe extensia fișierului. Acesta citește antetul binar (file plus semnăturile de tip magic bytes), astfel încât un fișier redenumit eronat nu poate induce sistemul în eroare.

  • Detecție automată a distribuției: Citește variabilele ID și ID_LIKE din /etc/os-release pentru a ști dacă trebuie să apeleze apt, dnf, zypper sau mecanismele specifice de pachete.

  • Diagnostic clar pentru formate incompatibile: Dacă utilizatorul dă click-dreapta pe instalatoare de Windows sau macOS (.exe, .msi, .dmg, .pkg), Teku nu încearcă lansări oarbe; în schimb, afișează un dialog explicativ clar prin care informează utilizatorul că acel format a fost compilat pentru Windows sau macOS și nu poate rula nativ pe Linux.

Matricea de formate suportate

Format fișierDistribuții compatibileAcțiune executată de Teku
.debDebian, Ubuntu, Linux Mint, Pop!_OS, Zorin OSInvocă apt install ./pachet.deb (rezolvând automat și dependențele externe din depozite).
.rpmFedora, RHEL, openSUSEApelează dnf install (pe Fedora/RHEL) sau zypper install (pe openSUSE).
.AppImageUniversal (orice distribuție Linux)Oferă executabilitate (chmod +x), îl integrează opțional în ~/Applications și îi creează intrare de lansare pe desktop.
.flatpakref / .flatpakDistribuții cu Flatpak instalatDeclanșează instalarea prin runtime-ul Flatpak de sistem.
.tar.gz / .tar.xzUniversalIdentifică dacă arhiva conține binare precompilate portabile sau scripturi de instalare (install.sh).
.exe / .msi / .dmgNon-LinuxAfișează un mesaj informativ despre incompatibilitatea platformei.

Interfață minimalistă și integrare în managerul de fișiere

Teku refuză deliberat interfețele greoaie. Întreaga experiență vizuală este formată din mici ferestre popup concise (folosind Zenity și stilul întunecat al sistemului):

  1. Confirmare (Confirm) → 2. Progres în timp real (Progress) → 3. Finalizat sau Eroare (Done / Error).

  • Polkit nativ (pkexec): Pentru acțiunile care cer drepturi de root (apt, dnf, zypper), Teku utilizează agentul grafic Polkit al mediului desktop curent (GNOME, KDE Plasma, Cinnamon, Xfce) pentru a solicita parola într-o casetă nativă securizată.

  • Integrare în meniul contextual:

    • GNOME Files (Nautilus): Se integrează ca acțiune principală de nivel superior prin extensia python3-nautilus;

    • KDE Dolphin / Nemo / Thunar: Se integrează prin acțiuni de tip ServiceMenu sau meniul Open With (Deschide cu...).

  • Jurnalizare detaliată: Toate operațiunile sunt salvate în ~/.local/state/teku/. Fișierul last.log păstrează detaliile celei mai recente execuții (esențial pentru diagnosticarea dependențelor rupte), iar history.log ține evidența pachetelor instalate.

De ce NU este distribuit pe Flathub sau Snap Store?

Dezvoltatorul menționează explicit că Teku nu poate fi împachetat ca Flatpak sau Snap: mecanismele stricte de izolare (sandboxing) din Flatpak și Snap blochează intenționat accesul la instalarea pachetelor de sistem pe gazdă și modificarea meniurilor contextuale ale managerului de fișiere — exact rolul fundamental al lui Teku.

Instalare rapidă pe distribuțiile Linux

Proiectul oferă un script oficial de instalare automată care detectează distribuția și trage pachetul corespunzător:

Bash
curl -fsSL https://raw.githubusercontent.com/anuzdhk/teku/main/install.sh | bash

Alternativ, se pot instala manual pachetele precompilate din secțiunea GitHub Releases:

  • Debian / Ubuntu / Mint:

    Bash
    sudo apt install ./teku_0.1.1_all.deb
nautilus -q   # repornește managerul de fișiere pentru încărcarea meniului

  • Fedora / RHEL:

    Bash
    sudo dnf install ./teku-0.1.1-1.fc44.noarch.rpm

  • Universal (AppImage): Rularea o singură dată a fișierului Teku-0.1.1-x86_64.AppImage va afișa un dialog care întreabă automat dacă doriți adăugarea comenzii în meniul de click-dreapta al sistemului.
