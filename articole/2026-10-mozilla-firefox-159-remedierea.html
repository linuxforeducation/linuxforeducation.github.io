Mozilla Firefox 159: Remedierea detașării filelor pe Wayland, optimizări de memorie pe GPU-uri AMD, căutare dedicată în file și monitorizare automată de pagini web

Mozilla a publicat oficial Firefox 159, cea mai recentă versiune stabilă a navigatorului său web open-source. Această lansare aduce corecții esențiale pentru utilizatorii de Linux — în special cei care rulează sesiuni native Wayland sau plăci grafice AMD —, alături de remapări ergonomice de scurtături pentru căutarea filelor, instrumente automate de monitorizare a paginilor web (webpage monitoring) și optimizări pentru aplicațiile web complexe.

Corecții critice pentru Linux: Wayland, AMD GPU și Memory Leaks

Versiunea 159 elimină câteva dintre cele mai frustrante probleme de comportament raportate pe platformele Linux:

  • Remedierea detașării accidentale a filelor pe Wayland: A fost rezolvat un bug deranjant prin care un simplu clic pe o filă în sesiunile Wayland o putea interpreta eronat ca o acțiune de glisare (drag-to-detach), detașând-o instantaneu într-o fereastră complet separată.

  • Consum excesiv de memorie pe plăcile grafice AMD: Corectarea unei scurgeri masive de resurse GPU/RAM pe sistemele Linux dotate cu grafică AMD la vizualizarea hărților interactive sau a rezultatelor geografice pe platforme precum ChatGPT sau servicii de cartografiere web.

  • Memory leak la ferestre minimizate (Zoom Web App): S-a rezolvat problema prin care rularea aplicațiilor web intensive de conferințe (precum Zoom Web) cu fereastra minimizată ducea la acumularea rapidă și necontrolată de memorie RAM în procesele de conținut Firefox.

  • Respectarea setării „Reduce Motion” / Animații oprite: S-a corectat anomalia prin care meniurile contextuale și panourile de setări continuau să afișeze animații de apariție treptată (fade-in), chiar dacă utilizatorul dezactivase explicit animațiile la nivelul sistemului de operare (Linux și Windows).

Ergonomie: Căutare rapidă în file și parole în Sidebar

Pentru utilizatorii care mențin zeci sau sute de file deschise simultan:

FuncționalitateModificare / Scurtătură nouă
Căutare în file deschise (Tab Search)Accesibilă prin noua scurtătură globală Ctrl + Shift + A pe Linux și Windows (respectiv Cmd + Shift + A pe macOS). Permite filtrarea instantanee a listei de file active.
Remapare scurtătură Extensii/TemePentru a elibera combinația de mai sus, panoul de Extensions & Themes a fost mutat pe Ctrl + Shift + F pe Linux/Windows (și Cmd + Shift + E pe macOS).
Parole în bara laterală (Sidebar)Managerul de parole salvate este acum inclus în mod implicit direct în bara laterală (Firefox Sidebar), fără a mai necesita configurare manuală din opțiunile de personalizare.

Inovație funcțională: Monitorizarea paginilor web prin „Smart Window”

Firefox 159 începe distribuirea treptată (progressive rollout) a unei funcționalități integrate de monitorizare a modificărilor pe paginile web, eliminând necesitatea extensiilor terțe invazive:

  • Comanda /watch în Smart Window: Utilizatorii pot instrui browserul, direct dintr-o interfață de chat din panoul Smart Window, să supravegheze o pagină pentru evenimente specifice (de exemplu: scăderi de preț, actualizări de stoc sau modificări de conținut), stabilind frecvența verificărilor automate.

  • Alerte și notificări native: La detectarea modificării, browserul afișează o notificare de sistem, iar butonul Tasks din bara de unelte afișează un indicator vizual punctiform.

  • Consolă de administrare: Toate sarcinile de supraveghere pot fi inspectate, puse pe pauză, forțate manual sau șterse accesând adresa internă:

    Plaintext
    about:smartwindowtasks

Remedierea stivelor de rețea, dialogurilor și sistemelor de fișiere

  • Fallback de rețea HTTP/3 la HTTP/2: Corectarea erorilor prin care platforme colaborative precum Slack refuzau să se încarce complet dacă conexiunea de tip HTTP/3 era respinsă la nivel de rețea, în loc să declanșeze automat mecanismul de retragere la HTTP/2.

  • Import din Google Chrome: Rezolvarea defectelor de sincronizare a semnelor de carte (bookmarks) la importul direct din profiluri Chrome asociate unui cont activ Google.

  • Dialogul de încărcare fișiere (Upload Picker): Firefox nu mai deschide directorul ultimei salvări de fișiere (Download directory) atunci când se solicită un upload, ci ține minte corect ultimul director utilizat pentru încărcări de documente.

  • Remedieri dropdown: Rezolvarea afișajului eronat al listelor derulante foarte lungi din formularele web, care arătau spații goale în loc de ultimele opțiuni din listă.

Noutăți pe macOS și Android

  • macOS: Integrarea ferestrei native de partajare a sistemului (native share picker), permițând trimiterea rapidă a link-urilor sau a mai multor file selectate simultan prin AirDrop, mesagerie sau alte aplicații de sistem. Corecții pentru intrările de gamepad în jocurile pe web și pentru utilitarele Apple Writing Tools.

  • Android: Optimizări dedicate pentru prevenirea reîncărcărilor agresive ale filelor din memorie (în special pe telefoanele Xiaomi și Redmi cu reguli agresive de baterie), rezolvarea blocajelor video pe anumite site-uri și eliminarea bug-ului care reducea la tăcere alertele/alarmele telefonului în timpul redării fluxurilor video.

Disponibilitate și descărcare

Binarele Firefox 159 sunt disponibile pe serverele oficiale de descărcare Mozilla. Pentru distribuțiile Linux, pachetele native vor sosi prin intermediul depozitelor oficiale (Ubuntu, Fedora, Arch Linux, openSUSE), precum și prin canalele Snap și Flatpak (Flathub).
