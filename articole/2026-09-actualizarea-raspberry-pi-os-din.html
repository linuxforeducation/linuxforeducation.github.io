Actualizarea Raspberry Pi OS din septembrie 2026 aduce un nou dock, un instrument de screenshot și kernel 6.18.50 LTS


Raspberry Pi a lansat o nouă actualizare pentru Raspberry Pi OS în septembrie 2026, care aduce îmbunătățiri majore pentru experiența desktop, inclusiv un nou dock, opțiuni reorganizate în Control Centre, un nou instrument de screenshot, modificări la managerul de fișiere și kernel-ul Linux 6.18.50 LTS.

🔹 Ce noutăți aduce actualizarea din septembrie 2026?

✅ Nou dock în wf-panel-pi:

  • Suport pentru dock a fost adăugat în wf-panel-pi, panoul desktop pentru medii Wayland din Raspberry Pi OS.
  • Au fost introduse două noi plugin-uri:
    • wfplug-imenu (v0.9): Un meniu cu icoane pentru lansarea aplicațiilor.
    • wfplug-wlist (v0.8): O listă de sarcini bazată pe icoane pentru afișarea ferestrelor deschise.
  • Imaginea 64-bit Trixie vine cu wf-panel-pi v1.31.

✅ Opțiuni de layout pentru dock:

  • Utilizatorii pot comuta între mai multe layout-uri bazate pe dock în secțiunea Defaults din Control Centre.
  • A fost adăugat un nou preset pentru ecrane foarte mari, deoarece atât wf-panel-pi, cât și lxpanel-pi (orientat către X11) suportă acum icoane de 96×96 pixeli.

✅ Control Centre reorganizat:

  • Un nou panou "Dock" gestionează configurarea dock-ului.
  • Un nou panou "Widgets" controlează acum setările dock-ului și barei de sarcini, care anterior erau gestionate printr-un dialog în wf-panel-pi.
  • Notificările au fost mutate în propriul panou din Control Centre, înlocuind dialogul anterior din wf-panel-pi.
  • Un nou panou "Shortcuts" permite utilizatorilor să vizualizeze și configureze scurtăturile de tastatură ale sistemului.

✅ Îmbunătățiri ale barei de sarcini:

  • Panoul Taskbar oferă acum opțiuni pentru a ascunde automat bara de sarcini și a preveni suprapunerea cu ferestrele maximizate.

✅ Opțiuni pentru desktop:

  • Panoul Desktop adaugă o opțiune pentru a folosi swaybg în loc de PCManFM pentru desenarea fundalului desktop.

✅ Nou instrument de screenshot:

  • Un nou utilitar de screenshot permite utilizatorilor să aleagă acțiunea implicită după capturarea unei screenshot-uri, cum ar fi deschiderea imaginii sau copierea în clipboard.

✅ Managerul de fișiere pcmanfm-pi:

  • Un nou build monolit numit pcmanfm-pi combină PCManFM și libfm într-o singură aplicație (versiunea 1.6 este inclusă în imaginea din septembrie).
  • Pentru gestionarea unităților externe, utilizatorii pot acum activa sau dezactiva montarea automată prin plugin-ul ejecter panel.
  • PCManFM nu mai montează automat unitățile externe implicit.

✅ Îmbunătățiri ale arhitecturii plugin-urilor:

  • Arhitectura plugin-urilor wf-panel-pi a fost reproiectată astfel încât plugin-urile nu mai necesită fișiere metadata XML pentru valorile implicite.
  • Structura sursei plugin-urilor a fost, de asemenea, reorganizată pentru a face comportamentul mai consistent între lxpanel-pi și wf-panel-pi.

✅ Schimbări în suportul Wayland:

  • Pe măsură ce Raspberry Pi consolidează desktop-ul în jurul Labwc, suportul pentru compozitorul Wayfire a fost îndepărtat din panourile Screens, Mouse și Keyboard din Control Centre.
  • Stack-ul Wayland a fost, de asemenea, actualizat: atât Labwc, cât și wlroots au trecut la seria 0.20.

✅ Kernel-ul Linux:

  • Raspberry Pi OS a trecut la kernel-ul Linux 6.18.50 LTS.
  • Imaginea include pachete de kernel 6.18.50 dedicate pentru atât Raspberry Pi 2712, cât și pentru configurațiile ARMv8.

✅ Dispozitive suportate:

  • Actualizarea suportă o gamă largă de dispozitive, inclusiv:
    • Raspberry Pi 3B, 3B+, 3A+, 4B, 400, 5, 500, 500+
    • CM3, CM3+, CM4, CM4S, CM5
    • Zero 2 W

🔹 Cum să actualizați?

Utilizatorii pot actualiza o instalare existentă de Raspberry Pi OS din terminal cu:

bash
sudo apt update
sudo apt upgrade

Totuși, Raspberry Pi recomandă folosirea:

bash
sudo apt full-upgrade

deoarece aceasta gestionează schimbările de dependențe care pot să nu fie aplicate cu un upgrade obișnuit.
