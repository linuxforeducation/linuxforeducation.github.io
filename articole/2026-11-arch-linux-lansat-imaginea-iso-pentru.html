Arch Linux a lansat imaginea ISO pentru noiembrie 2026: Kernel 7.2.11, systemd 262.1 și pachete de sistem actualizate

roiectul Arch Linux a publicat snapshot-ul lunar de instalare pentru luna noiembrie 2026 (versiunea 2026.11.01). Această imagine este destinată utilizatorilor care configurează sisteme noi de la zero, incluzând toate actualizările de pachete, corecțiile de securitate și noile drivere intrate în depozite pe parcursul lunii octombrie.

Elementul central al noului mediu de instalare este trecerea la Linux Kernel 7.2.11 (față de versiunea 7.2.7 livrată în imaginea din luna precedentă).

Nucleul sistemului și utilitare de bază

Imaginea integrează actualizări substanțiale pentru componentele esențiale ale distribuției:

  • Init și servicii de sistem: systemd 262.1 și mkinitcpio 42.2.

  • Rețea și securitate: curl 8.23 și OpenSSH 10.6p1.

  • Sisteme de fișiere: Btrfs-progs 7.3 și XFSProgs 7.2.1.

  • Rulaj și pachete: Python 3.14.9, alături de versiuni de dezvoltare pentru viitorul manager de pachete Pacman 7.1.

Grafică, medii desktop și aplicații de productivitate

Pe partea grafică și multimedia, mediul aduce componente de ultimă generație:

  • Drivere grafice: Stiva Mesa 26.2.6 (cu drivere Vulkan actualizate pentru Intel, AMD, Nouveau etc.) și driverul proprietar NVIDIA 615.78.08 cu suport CUDA 13.4.3. Subsystemul audio folosește PipeWire 1.6.10.

  • Medii de lucru: Depozitele oferă acum KDE Plasma 6.8.2 (împreună cu KDE Frameworks 6.31 și KDE Gear 26.08.2), noul mediu COSMIC Desktop 1.11, precum și pachete din suita GNOME 51 (inclusiv GNOME Shell și Mutter 51.1, Nautilus și GNOME Control Center).

  • Software zilnic și navigare: Firefox 159, Chromium 156, Thunderbird 158.0.1, LibreOffice 26.8.1, Calligra 26.08.2, Blender 5.2.3 și Audacious 4.6.2.

Ecosistem pentru dezvoltatori și containere

Dezvoltatorii și administratorii de sistem beneficiază de instrumente moderne gata de utilizare:

  • Compilatoare și limbaje: LLVM / Clang 23.1.4, Go 1.27.3, Node.js 26.13, Rust 1.99.1, OpenJDK 27.0.1 și biblioteca grafică Qt 6.12.

  • Virtualizare și containere: Docker 29.9.2, Podman 6.1.4, containerd 2.4.2, Buildah 1.45.2, QEMU 11.1.3 și VirtualBox 7.2.22.

  • Servicii web: Nginx 1.30.6 și platforma cloud Nextcloud 35.0.2.

Disponibilitate și instrucțiuni pentru utilizatorii curenți

Fiind o distribuție de tip rolling release, utilizatorii existenți de Arch Linux nu trebuie să descarce noua imagine ISO și nici să reinstaleze sistemul. O simplă sincronizare completă prin terminal aduce întregul sistem la zi:

Bash
sudo pacman -Syu

Imaginea ISO Arch Linux 2026.11.01 este disponibilă pentru descărcare directă sau prin rețeaua oficială de torrente și servere mirror, având ca scop facilitarea unei instalări curate fără necesitatea descărcării a sute de megabytes de actualizări chiar în timpul procesului de setup.
