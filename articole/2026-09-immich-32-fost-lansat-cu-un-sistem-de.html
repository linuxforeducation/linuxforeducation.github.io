Immich 3.2 a fost lansat cu un sistem de căutare redesenat și noi funcționalități


Immich, platforma populară open-source de gestionare a pozelor și videoclipurilor self-hosted, a lansat versiunea 3.2, care aduce un interfață de căutare web redesenată, un API de căutare v2 și noi funcții pentru automatizare și gestionare.

🔹 Ce noutăți aduce Immich 3.2?

✅ Interfață de căutare redesenată:

  • Filtrele sunt acum mai ușor de navigat, păstrând aceeași funcționalitate de bază.
  • Utilizatorii pot îngusta rezultatele folosind criterii precum:
    • Persoane
    • Locații
    • Date
    • Tag-uri
    • Albume
    • Modelul și obiectivul camerei
    • Statusul de favorit
    • Dacă un asset este arhivat
  • Termenii de căutare contextuală pot fi combinați cu aceste filtre.

✅ API de căutare v2:

  • API-ul de pe partea de server a fost reconstruit pentru a combina multiple filtre de căutare folosind operațiunile AND și OR.
  • Suportă cazuri de utilizare precum căutarea specifică în albume.

✅ Grupuri de cluster pentru recunoașterea fețelor:

  • O nouă funcție numită cluster groups permite utilizatorilor de încredere de pe aceeași instanță Immich să recunoască persoanele în pozele partajate.
  • Dacă o persoană este identificată în biblioteca dvs., Immich o poate recunoaște și în pozele partajate de alți membri ai grupului.
  • Limitare importantă: Pentru a aplica clusterizarea trans-utilizator retroactiv, recunoașterea facială trebuie resetată pentru toți din grup. Acest lucru va șterge numele și datele de naștere asociate fețelor recunoscute de machine learning, iar cluster-ele rezultate pot diferi ușor față de cele anterioare.

✅ Îmbunătățiri ale automatizării:

  • Fluxurile de lucru pot fi acum declanșate când un asset primește un tag.
  • Un nou filtru de tag-uri poate verifica dacă un asset corespunde tuturor, oricăror sau niciunui tag dintr-o listă specificată.
  • O acțiune de flux de lucru poate adăuga automat unul sau mai multe tag-uri unui asset.

✅ Pagină dedicată pentru "Memories":

  • Memoriile generate anterior nu mai dispar odată ce nu mai sunt afișate activ.
  • Noua pagină permite revenirea la memoriile anterioare, iar memoriile individuale pot fi marcate ca favorite pentru a rămâne disponibile permanent.

✅ Gestionarea tag-urilor îmbunătățită:

  • Tag-urile existente pot fi acum redenumite direct din interfața web Immich.

✅ Navigarea pe hartă îmbunătățită:

  • Un nou control permite utilizatorilor să afișeze o cronologie care conține toate pozele și videoclipurile localizate în aria vizibilă curentă a hărții.
  • Pe măsură ce harta este deplasată către o altă locație, cronologia se actualizează automat pentru a reflecta asset-urile conținute în noua zonă vizibilă.
  • Anunțul de lansare: Immich 3.2 Release on GitHub
