RustGIS: GIS complet și modern, scris 100% în Rust pentru viteză maximă, confidențialitate și analiză geospațială

În universul sistemelor informaționale geografice (GIS), software-uri precum QGIS și ArcGIS domină piața de decenii, însă adesea vin la pachet cu o complexitate ridicată a dependențelor, timpi mai mari de pornire și arhitecturi software moștenite. Proiectul RustGIS (dezvoltat sub umbrela organizației open-source opengeos, coordonată de prof. Qiusheng Wu / @giswqs) vine cu o propunere radicală: un software GIS performant, cross-platform și complet gratuit, rescris de la zero în Rust.

RustGIS îmbină viteza nativă a codului compilat cu siguranța memoriei caracteristică limbajului Rust, oferind un pachet unic: rulează nativ pe calculator, în terminal, ca bibliotecă Python sau direct în browser prin WebAssembly.

1. Performanță extremă: Aplicație nativă GPU, WebAssembly și fără servere obligatorii

Spre deosebire de soluțiile tradiționale greoaie, RustGIS a fost gândit din start pentru simplitate și viteză:

  • Executabil unic randat pe GPU: Folosește un nucleu grafic ultra-rapid (interfață modernă bazată pe egui și renderer tiny-skia), fără a necesita un server local sau componente runtime masive.

  • Direct în browser prin WebAssembly (Wasm): La web.rustgis.app, utilizatorii au acces la aceeași interfață și aceleași unelte de cartografie direct din navigator, fără instalare, folosind selectorul local de fișiere (datele nu părăsesc niciodată mașina).

  • Confidențialitate absolută: Fișierele sunt citite și modificate local. Rețeaua este interogată strict la cerere: pentru hărți de bază online (basemaps), depozitul de pluginuri sau modele AI configurate de utilizator.

2. Format larg de date și compatibilitate modernă (Cloud-Native GIS)

RustGIS nu se limitează la fișiere clasice, ci pune un accent puternic pe formatele cloud-native și baze de date moderne:

Tip de dateFormate și surse suportate nativ
VectorialGeoJSON, Shapefile (inclusiv arhive .zip), GeoPackage, GeoParquet, FlatGeobuf, CSV/TSV cu coordonate sau WKT, KML/KMZ, GPX, DXF, OpenStreetMap PBF. Suportă conexiuni directe la tabele PostGIS și interogări analitice SQL prin DuckDB Spatial.
Raster & Remote SensingCloud-Optimized GeoTIFF (COG), GeoTIFF obișnuit, grile ASCII, depozite Zarr 2 și 3 (serii temporale). Reproiecție dinamică (on-the-fly) din orice cod EPSG, compoziții de benzi satelitare, întindere de contrast, umbrire de relief (shaded relief) și clasificare automată (k-means, distanță minimă).
Cloud de puncte LiDARFișiere LAS, LAZ și Cloud Optimized Point Clouds (COPC), citite direct din fișier fără a suprasolicita memoria RAM.
Servicii web & TilesWMS, WMTS, WFS, OGC API Features, servicii ArcGIS REST, tile-uri raster XYZ/TMS și tile-uri vectoriale Mapbox Vector Tiles / stiluri MapLibre.

3. Arhitectură flexibilă: GUI clasic, Python, CLI și suport MCP pentru Inteligență Artificială

RustGIS are o abordare centrată pe comenzi: fiecare buton din panglică (Ribbon) este o comandă scriptabilă cu un ID propriu.

  1. Interfață intuitivă (Ribbon UI): Organizată logic pe fluxul de lucru geospațial: Home, Data, Style, Edit, Analyze, View, Publish, completată de un glob 3D interactiv, previzualizare stiluri, tabele de atribute sincronizate și un sistem complet de machetare pentru tipar (PDF/PNG la orice DPI).

  2. Integrare Python (PyO3 & PyPI): Pachetul rustgis permite instanțierea motorului în memorie și interacțiunea directă cu GeoPandas într-un notebook Jupyter sau Google Colab (pip install rustgis).

  3. Peste 1.000 de algoritmi geospațiali: Include colecțiile analitice GeoLibre și Whitebox Tools pentru hidrologie, calcul de pantă, analiză de vizibilitate (viewshed) și analiză de teren.

  4. AI Assistant & Server MCP: Include un panou de asistență AI care poate fi conectat la modele locale (prin Ollama) sau servicii precum Claude, OpenAI și Gemini. În plus, comanda rustgis-cli mcp permite utilizarea RustGIS ca un server Model Context Protocol (MCP), permițând asistenților de codare (Cursor, VS Code, Claude Code) să execute analize spațiale direct din conversație.

4. Instalare și pornire rapidă

Aplicația este distribuită sub licență Apache-2.0 și poate fi instalată prin multiple metode:

  • Windows: winget install OpenGeos.RustGIS

  • macOS: brew install --cask opengeos/rustgis/rustgis

  • Linux (Arch): yay -S rustgis-bin

  • Linux (Fedora): sudo dnf copr enable giswqs/rustgis && sudo dnf install rustgis

  • Direct din sursă (cu Rust 1.90+):

    Bash
    cargo run --release -p rustgis
