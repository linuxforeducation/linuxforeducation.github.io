WinBtrfs v1.10: Driverul Open-Source Btrfs pentru Windows a primit o nouă versiune

Depozitul oficial de pe GitHub al proiectului WinBtrfs (dezvoltat de Mark Harmstone) marchează lansarea versiunii v1.10, aducând îmbunătățiri majore de stabilitate, performanță și suport pentru funcționalitățile avansate ale sistemului de fișiere Btrfs nativ din Linux atunci când este accesat din Microsoft Windows.

✨ Punctele cheie ale actualizării WinBtrfs v1.10:

🛠️ Compatibilitate sporită cu subvolumele și snapshot-urile Linux: • Îmbunătățește gestionarea subvolumelor Btrfs și a snapshot-urilor create inițial din mediul Linux, permițând montarea și citirea/scrierea mai sigure sub Windows fără riscul de corupere a metadatelor.

⚡ Optimizări de performanță la citire și scriere: • Refacerea și rafinarea algoritmilor de gestionare a memoriei cache din Windows Kernel pentru a accelera rata de transfer la lucrul cu fișiere de mari dimensiuni sau la procese intensive de I/O.

🛡️ Corecții de stabilitate și bug-uri critice: • Rezolvă probleme legate de prăbușirea sistemului (BSOD) în timpul operațiunilor de deconectare neașteptată a discurilor exterioare sau la gestionarea volumelor ce folosesc compresie nativă (zlib, lzo, zstd).

🌐 Suport extins pentru permisiuni (ACL-uri): • Traducere și mapare mai precisă a atributelor și permisiunilor de fișiere între sistemul POSIX/Linux și modelul de securitate Windows (NTFS/ACL).

🔗 Sursă și articol complet: https://github.com/maharmstone/btrfs#winbtrfs-v110

📌 Concluzie:

WinBtrfs v1.10 continuă să fie un pod esențial între lumea Windows și ecosistemul Linux, oferind utilizatorilor dual-boot o modalitate rapidă și sigură de a accesa partițiile Btrfs direct din SO-ul Microsoft! 🚀
