Swell (ivantacca/swell): Navigator web minimal bazat pe Gecko (Firefox ESR) cu bară laterală stil Arc și izolare completă la nivel de Spațiu / Container

În contextul retragerii sau schimbării de direcție a browserelor inovatoare de generație nouă (cum a fost The Browser Company cu Arc Browser) și al dominației covârșitoare a motorului Blink/Chromium pe piața browserelor cu interfață verticală, proiectul open-source Swell (creat de Ivan Tacca sub licență MPL-2.0) propune o alternativă tehnică rară și ambițioasă: o aplicație independentă bazată pe motorul Gecko de la Mozilla (Firefox ESR), care duce conceptul de containere la nivelul unui profil complet izolat (per-space profile isolation).

Swell nu este o extensie de browser sau un script userChrome.css, ci o aplicație Gecko de sine stătătoare, menținută ca o coadă de patch-uri peste Firefox ESR — similar modului în care clientul de e-mail Thunderbird trăiește în arborele Mozilla sub comm/.

Inovația cheie: Izolare completă pe 17 subsisteme (Per-Space Isolation)

În Firefox-ul clasic, funcția Multi-Account Containers separă doar cookie-urile, localStorage și cache-ul de rețea, în timp ce istoricul de navigare, completarea automată de formulare, parolele salvate și extensiile rămân globale. Swell elimină această breșă de confidențialitate prin izolarea strictă a fiecărui Spațiu (Space):

  • Izolare pe 17 depozite de date (stores): Fiecare spațiu creat deține propriile:

    • Cookie-uri și site storage;

    • Istoric de navigare și locuri (places history);

    • Formulare salvate și date de autofill;

    • Parole, adrese și carduri salvate;

    • Extensii WebExtensions proprii (un ad-blocker sau un utilitar de dev poate fi instalat doar într-un anumit spațiu);

    • Permisiuni acordate site-urilor (cameră web, microfon, partajare ecran);

    • Descărcări și nivel de zoom per-site.

  • Criptare separată în Keychain / Secret Service: Credențialele și parolele fiecărui spațiu sunt criptate cu chei criptografice dedicate stocate în keyring-ul sistemului de operare (libsecret pe Linux / macOS Keychain).

  • Ștergere totală (Zero Residue): La eliminarea unui spațiu, toate cele 17 depozite asociate (istoric, cookie-uri, credențiale) sunt șterse instantaneu și definitiv de pe disc.

  • Suită de testare automată: Include un script riguros de verificare (tools/isolation.sh) care efectuează teste end-to-end pentru a depista și preveni scurgerile de date între spații diferite.

Ergonomie: Interfață stil Arc și Bară de Comenzi

Swell aduce o organizare vizuală modernă și productivă, direct inspirată de fluxul de lucru Arc:

Element UIFuncționalitate și Comportament
Arborele lateral (Sidebar Tree)Structurat pe secțiunile: Favorites (aplicații web fixate permanent în partea de sus), Pinned Tabs & Folders (file organizate în dosare specifice spațiului activ) și Today (file temporare deschise în cursul zilei).
Bara de comenzi (Command Bar)Dialog central accesibil din tastatură pentru deschiderea rapidă de URL-uri, căutare instantanee, salt între spații sau comenzi de sistem.
Anulare rapidă (Cmd/Ctrl + Z)Permite restaurarea imediată a unui rând, filă sau dosar închis accidental din bară.
Importator Arc nativInclude instrument dedicat pentru migrarea automată a structurii de spații și foldere din fișierul StorableSidebar.json al browserului Arc.

Confidențialitate absolută: Zero Telemetrie și fără actualizări forțate

Conceput conform principiilor riguroase de confidențialitate descrise în fișierul său PRIVACY.md:

  • Fără telemetrie Mozilla: Toate modulele de colectare de date, studiile SHIELD și sistemul de raportare a crash-urilor (crash reporter) sunt dezactivate sau eliminate complet.

  • Fără actualizări de fundal automate: Browserul nu instalează niciodată pachete nesolicitate; include doar o verificare zilnică pasivă pe GitHub pentru versiuni noi, care poate fi dezactivată complet din setări.

Arhitectură de dezvoltare și compilare

Swell este structurat curat în trei componente principale:

  1. app/: Aplicația grafică Gecko și podul de interfață;

  2. core/: Nucleul scris în Rust, care deține și orchestrează întreaga stare a spațiilor și izolării;

  3. patches/: Coada de patch-uri minimale aplicate peste versiunea fixată în FIREFOX_REV (în prezent bazat pe Firefox ESR 153.6.0).

Construirea din surse se realizează prin uneltele standard Mozilla mach:

Bash
git clone --filter=blob:none https://github.com/mozilla-firefox/firefox firefox
git clone https://github.com/ivantacca/swell firefox/swell
firefox/swell/tools/setup.sh --checkout   # aplică patch-urile peste Firefox ESR
cd firefox
export MOZCONFIG=$PWD/swell/mozconfig.linux
./mach bootstrap && ./mach build

Disponibilitate și instalare

Aflat în stadiul Alpha activ, proiectul oferă versiuni precompilate pentru dezvoltatori și entuziaști:

  • Linux (x86_64): Pachetul binar este livrat ca arhivă comprimată Swell-<version>-<arch>.tar.xz.

    Bash
    tar -xf Swell-*.tar.xz
cd Swell/
./install.sh   # integrează automat Swell în meniul de aplicații (.desktop)
# Pentru dezinstalare: ./install.sh --uninstall

    (Cerințe pe Linux: biblioteci GTK 3 și daemonul libsecret activ pentru criptarea parolelor).

  • macOS: Imagini de disc .dmg pentru arhitectura Apple Silicon (ARM64). (Deoarece build-ul alpha nu este încă semnat/notarizat de Apple, necesită deschidere prin click-dreapta > Open sau eliminarea flag-ului de carantină cu xattr -dr com.apple.quarantine /Applications/Swell.app).

  • Windows: Build-ul dedicat se află pe foaia de parcurs pentru versiunile următoare.
