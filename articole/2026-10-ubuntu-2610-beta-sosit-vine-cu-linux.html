Ubuntu 26.10 Beta a sosit: Vine cu Linux Kernel 7.3-rc și mediul desktop GNOME 51

Canonical a lansat oficial versiunea Ubuntu 26.10 Beta ("Oracular Ocelot"), marcând ultima etapă majoră de testare înainte de lansarea finală programată pentru sfârșitul acestei luni. Noua versiune include componente de ultimă generație din ecosistemul open-source, evidențiindu-se prin integrarea versiunii preliminare Linux Kernel 7.3-rc și a noului mediu de lucru GNOME 51.

Cele mai importante noutăți din Ubuntu 26.10 Beta

  • Linux Kernel 7.3-rc: Incorporarea timpurie a seriei de kernel 7.3 aduce îmbunătățiri majore pentru suportul de componente hardware recente, performanțe superioare în gestionarea memoriei și optimizări pentru cipurile grafice de ultimă generație.

  • Mediu de lucru GNOME 51:

    • Interfață grafică rafinată, cu o navigare mai fluidă și animații optimizate.

    • Centru de control (Settings) reorganizat pentru acces mai rapid la opțiunile de afișaj, rețea și confidențialitate.

    • Performanță sporită și latență redusă în sesiunile implicite Wayland.

  • Instalator de sistem actualizat: Continuă dezvoltarea noului instalator bazat auf Flutter, aducând opțiuni mai clare pentru configurarea partițiilor, criptarea discului și gestionarea profilurilor de utilizator.

  • Stivă software și instrumente de dezvoltare la zi: Include ultimele versiuni ale suitei LibreOffice, browserului Firefox, precum și pachete actualizate pentru compilatoarele GCC, Clang și mediile de execuție Python, Rust și Go.
