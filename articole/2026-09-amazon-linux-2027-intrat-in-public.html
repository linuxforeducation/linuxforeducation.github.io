Amazon Linux 2027 a intrat în Public Preview cu Linux Kernel 7.1 și DNF5

☁️ Amazon Linux 2027 a intrat în Public Preview cu Linux Kernel 7.1 și DNF5!


Publicația Linuxiac detaliază lansarea primei versiuni de previzualizare publică (Public Preview) pentru Amazon Linux 2027 (AL2027), următoarea generație a sistemului de operare dezvoltat de Amazon Web Services (AWS) și optimizat pentru rularea sarcinilor de lucru în cloud.

✨ Punctele cheie ale lansării Amazon Linux 2027:

🐧 Nucleu Linux 7.1 modern:
• Sistemul vine echipat din fabrică cu nucleul Linux 7.1, aducând suport extins pentru cele mai noi generații de procesoare (inclusiv arhitecturile moderne AWS Graviton/ARM și x86_64) și performanțe sporite la nivel de I/O și rețea.

⚡ Tranziția la administratorul de pachete DNF5:
• Înlocuiește versiunea anterioară DNF/YUM cu DNF5, oferind o viteza considerabil crescută la rezolvarea dependențelor, un consum redus de memorie și execuție mai rapidă a comenzilor de instalare/actualizare.

🛡️ Securitate consolidată și profil SELinux îmbunătățit:
• Include implicit configurații stricte de securitate, politici SELinux actualizate și module de criptare conforme cu cele mai recente standarde industriale pentru protejarea infrastructurilor din cloud.

🚀 Optimizare profundă pentru ecosistemul AWS:
• Integrare nativă cu serviciile AWS (EC2, ECS, EKS) și timp de pornire (boot time) redus la minim pentru instanțele virtuale și containere.

📌 Concluzie:

Amazon Linux 2027 setează un nou standard pentru infrastructurile cloud-native, combinând tehnologii de vârf din ecosistemul Linux cu optimizări dedicate pentru sarcinile de lucru la scară înaltă! 🚀
