Rufix (thuutien/rufix): Utilitar open-source în stilul Rufus pentru formatarea stick-urilor USB și crearea de medii bootabile pe Linux (GTK3)

Pentru utilizatorii care fac tranziția de la Windows la Linux, una dintre aplicațiile a căror lipsă se resimte cel mai acut este Rufus — utilitarul recunoscut pentru simplitatea, fiabilitatea și controlul detaliat asupra tabelelor de partiții (MBR/GPT), sistemelor de fișiere și suportului nativ pentru imagini Windows fără configurări manuale obscure. Pe Linux, uneltele convenționale precum BalenaEtcher sau comenzile brute dd scriu adesea imaginile în mod strict hibrid/RAW, limitând flexibilitatea partițiilor sau întâmpinând probleme la scrierea imaginilor oficiale de Windows.

Proiectul open-source Rufix (dezvoltat de @thuutien sub licența liberă GPL-3.0) a fost creat tocmai pentru a umple acest gol: este o clonă directă în stilul Rufus (Rufus-style USB formatter and bootable drive creator), construită cu o interfață nativă pe GTK3 pentru mediile grafice Linux.

Arhitectură și abordare funcțională

Rufix transpune ergonomia și logica clasică a lui Rufus pe subsistemele native Linux:

  • Interfață compactă în stil Rufus (GTK3): Păstrează dispunerea verticală familiară — selectarea dispozitivului USB țintă, alegerea imaginii ISO, schema de partiționare (MBR vs. GPT), sistemul țintă (BIOS / UEFI) și eticheta volumului.

  • Formatare și pregătire avansată a stocării: Spre deosebire de inscripționarea brută sector-cu-sector (dd) care blochează capacitatea utilă a stick-ului în format read-only, Rufix formatează și creează sisteme de fișiere reale (FAT32, NTFS, ext4) pe partițiile țintă.

  • Control al tabelei de partiții: Folosește utilitarele de sistem util-linux și comanda partprobe (prin biblioteca parted) pentru a forța recitirea tabelelor de partiții de către kernel fără a fi necesară deconectarea fizică a stick-ului.

Soluționarea problemei Windows ISO pe Linux: Suport wimlib

Una dintre marile dificultăți tehnice la crearea unui stick USB bootabil pentru Windows pe Linux o reprezintă fișierul install.wim din imaginile moderne de Windows 10/11, care depășește frecvent limita maximă de 4 GB impusă de sistemul de fișiere FAT32 (necesar pentru bootarea nativă UEFI pe majoritatea plăcilor de bază).

ComponentăRol în Rufix
wimlib / wimtoolsDependență opțională recomandată. Rufix utilizează biblioteca wimlib pentru a fragmenta automat fișierele masive install.wim în părți mai mici de 4 GB (install.swm), permițând scrierea unei imagini complete de Windows pe un stick FAT32 compatibil cu standardul UEFI fără erori de depășire a dimensiunii.
parted / partprobeAsigură re-indexarea instantanee a noilor tabele MBR/GPT create pe dispozitivul USB.

Disponibilitate și instalare pe distribuțiile Linux

Aplicația a fost inclusă recent în depozitele comunitare și poate fi compilată sau instalată pe principalele distribuții:

  • Arch Linux (AUR): Pachetul este disponibil în depozitul comunitar AUR sub numele rufix:

    Bash
    yay -S rufix
# sau
paru -S rufix

    (Pentru suportul complet al imaginilor Windows, asigurați-vă că instalați și dependența opțională wimlib).

  • Debian / Ubuntu / Linux Mint: Necesită instalarea uneltelor de sistem recomandate (wimtools, parted, pachetele de bază GTK3):

    Bash
    sudo apt install wimtools parted

    și compilarea/rularea din depozitul sursă clonat de pe GitHub.
