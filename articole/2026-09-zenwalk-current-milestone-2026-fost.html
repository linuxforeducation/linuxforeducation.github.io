Zenwalk Current Milestone 2026 a fost lansat cu nucleul Linux 7.1 și integrare Flatpak


Publicația Linuxiac informează despre lansarea unei noi versiuni de test/snapshot pentru distribuția bazată pe Slackware Zenwalk GNU/Linux (ediția Current Milestone 2026), aducând pachete moderne, optimizări de performanță și o punte de legătură între mediul tradițional Slackware și ecosistemele moderne de aplicații.

✨ Punctele cheie ale lansării Zenwalk Current Milestone 2026:

🐧 Nucleu modernizat (Linux Kernel 7.1.7):

• Include versiunea recentă a nucleului Linux 7.1.7, furnizând suport extins pentru componente hardware de ultimă generație, gestionare optimizată a energiei și drivere grafice actualizate.

🖥️ Desktop Xfce 4.20 rafinat:

• Continuă tradiția Zenwalk de a oferi un mediu de lucru rapid și minimalist bazat pe Xfce 4.20, configurat cu un aspect curat, modernizat și pregătit pentru utilizarea zilnică imediat după instalare.

📦 Integrare completă Flatpak:

• Răspunzând cerințelor de accesibilitate la software modern, snapshot-ul integrează nativ suportul pentru pachete Flatpak (cu acces direct la Flathub), permițând instalarea rapidă a aplicațiilor grafice fără dependențe complexe de pachete Slackware create manual.

⚙️ Urmărirea ramurii Slackware-Current:

• Aliniat cu arborele de dezvoltare Slackware Current, sistemul oferă utilizatorilor cel mai recent stack de biblioteci, compilatoare și componente de sistem, menținând în același timp compatibilitatea 100% cu structura Slackware.

📌 Concluzie:

Zenwalk Current Milestone 2026 demonstrează cum o distribuție clasică bazată pe Slackware poate rămâne extrem de relevantă, îmbinând minimalismul tradițional cu nucleul Linux 7.1 și ecosistemul modern Flatpak! 🚀
