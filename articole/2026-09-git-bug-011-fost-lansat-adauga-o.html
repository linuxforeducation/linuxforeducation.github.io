git-bug 0.11 a fost lansat: Adaugă o interfață Web completă pentru probleme și navigare în cod

Proiectul open-source git-bug a primit o actualizare majoră — versiunea 0.11. Aceasta aduce o interfață Web completă (Web UI) ce permite gestionarea tichetelor/problemelor (issues) și explorarea codului sursă direct din browser, funcționând complet offline și fără dependență de platforme centralizate.

Ce este git-bug și cum funcționează?

Spre deosebire de sistemele tradiționale de bug-tracking (cum ar fi cele din GitHub, GitLab sau Jira), git-bug stochează toate problemele, comentariile și etichetele direct în interiorul repozitoriului Git ca obiecte native. Această arhitectură oferă avantaje majore:

  • 100% Offline: Puteți crea, edita și închide tichete chiar și fără o conexiune la internet.

  • Sincronizare automată: Datele despre probleme sunt trimise și preluate odată cu comenzile standard git push și git pull.

  • Fără blocare în platformă (Vendor Lock-in): Datele rămân în repozitoriul dumneavoastră, indiferent unde este găzduit proiectul.

Noutățile principale din git-bug v0.11

  • Interfață Web încorporată (Web UI): Permite lansarea unui server local care oferă o interfață vizuală intuitivă pentru crearea, filtrarea și gestionarea tichetelor de erori.

  • Explorator de cod (Code Browsing): Utilizatorii pot naviga prin ramurile repozitoriului (branches), pot inspecta istoricul commit-urilor și pot vizualiza fișierele din cod direct din interfața Web locală.

  • Sincronizare hibridă: Păstrează posibilitatea de import și export al datelor către și dinspre platforme precum GitHub, GitLab, Jira sau Launchpad.

Exemplu rapid de utilizare

Puteți porni interfața Web locală direct din linia de comandă, în cadrul oricărui proiect Git:

Bash
# Lansarea interfeței Web în browser
git bug webui

# Sau gestionarea tichetelor direct din terminal (CLI)
git bug issue create
git bug issue ls
