Pittore Studio: Un editor foto stratificat (layer-based) nativ și exclusiv pentru Linux

Lipsa unei suite foto profesionale native cu flux de lucru identic cu cel din Adobe Photoshop sau Affinity Photo a rămas multă vreme unul dintre marile compromisuri pentru creatorii de conținut vizual de pe Linux. Deși instrumente precum GIMP sau Krita acoperă o gamă largă de nevoi, mulți graficieni preferă arhitectura clasică orientată pe straturi (layers), măști dinamice și editare non-destructivă.

Dezvoltat sub umbrela organizației Event-Horizon-desktop-environment (de către creatorul proiectului Linux-Affinity-Installer / MattsCreative / @ryzendew), Pittore Studio este un nou editor foto grafic construit nativ și exclusiv pentru platformele Linux.

De ce un nou editor? Trecerea de la straturi de compatibilitate la software nativ

Inițiatorul proiectului a devenit cunoscut în comunitate pentru eforturile de a rula suita comercială Affinity (Photo, Designer, Publisher) pe Linux prin Wine, scripturi de optimizare și accelerare GPU (DXVK, vkd3d-proton). Totuși, dependența continuă de o aplicație proprietară de Windows implică mereu riscul ca actualizările viitoare să strice compatibilitatea.

Pittore Studio reprezintă pasul către independență completă: o aplicație independentă dedicată editării raster/foto pe Linux, gândită din start pentru performanță nativă.

Principalele caracteristici și filozofia proiectului

  • Flux de lucru bazat pe straturi (Layer-Based): Conceput să ofere ergonomia și ierarhia de straturi cu care sunt obișnuiți utilizatorii din Photoshop și Affinity Photo.

  • Exclusiv pentru Linux: Nu încearcă să fie un port cross-platform hibrid; dezvoltarea este canalizată direct pe integrarea cu subsistemele desktop Linux moderne (Wayland, X11, accelerare grafică directă).

  • Proiect integrat în ecosistemul Event Horizon: Face parte din suita de aplicații concepute pentru mediul desktop independent Event Horizon Desktop Environment / Otter Shell.

Disponibilitate și testare inițială

Proiectul a publicat primele versiuni de testare timpurie (v0.1.0) sub formă de imagini independente, invitând comunitatea de graficieni și entuziaști Linux să testeze fluxurile de lucru și să trimită feedback:

  • Format AppImage: Permite testarea imediată pe majoritatea distribuțiilor pe 64 de biți (Ubuntu, Fedora, Arch, openSUSE) fără a altera dependențele din sistem.

  • Depozit oficial: Codul sursă și lansările sunt găzduite public pe GitHub.
