NVIDIA publică vGPU Manager și driver-ul de variantă VFIO pentru driver-ul open-source Nova


Site-ul Phoronix raportează transmiterea unei serii de 13 patch-uri de către inginerii NVIDIA către comunitatea Linux, aducând suport pentru vGPU Manager și un driver de variantă VFIO conceput special pentru driver-ul open-source scris în Rust Nova (nova-core).

✨ Punctele cheie ale propunerii NVIDIA pentru driver-ul Nova:

🖥️ Virtualizare GPU avansată (vGPU) pe kernel-ul Linux: • NVIDIA extinde capabilitățile driver-ului open-source Nova adăugând infrastructura necesară pentru partajarea și virtualizarea resurselor GPU (vGPU) în medii de date și mașini virtuale (VMs).

⚙️ Driver de variantă VFIO dedicat: • Integrarea unui driver de variantă VFIO (Virtual Function I/O) permite atașarea directă și gestionarea eficientă a resurselor GPU în mașinile virtuale, beneficiind de arhitectura nova-core bazată pe procesorul de firmware GSP (GPU System Processor).

🦀 Continuarea dezvoltării ecosistemului Rust pe Linux: • Proiectul Nova continuă să fie un punct de referință pentru adoptarea limbajului Rust în kernel-ul Linux, facilitând suportul pentru plăcile grafice moderne NVIDIA (de la arhitectura Turing/Ampere până la generațiile recente Hopper și Blackwell).

☁️ Impact major pentru centrele de date și infrastructura cloud: • Această mutare apropie driver-ul open-source Nova de paritatea de funcționalități cu soluțiile proprietare NVIDIA destinate mediilor enterprise, ușurând integrarea pe hypervisori open-source precum KVM/QEMU.

🔗 Sursă și articol complet: https://www.phoronix.com/news/NVIDIA-Nova-vGPU-Manager

📌 Concluzie:

Implicarea activă a NVIDIA în adăugarea suportului vGPU pentru driver-ul Rust Nova confirmă angajamentul de a oferi o suită open-source de nivel enterprise pentru virtualizare în Linux! 🚀
