CutefishOS renaște sub numele Cutefish: Mediu grafic refăcut, imagini bazate pe Debian 13 și rularea aplicațiilor macOS pe Linux

Distribuția Linux cunoscută anterior pentru aspectul său puternic inspirat din ecosistemul Apple a revenit oficial sub o nouă identitate simplificată: Cutefish. Proiectul marchează un nou început ambițios, introducând un mediu desktop reconstruit de la zero, imagini de instalare zilnice (nightly ISOs) bazate pe Debian 13 „Trixie” și un strat revoluționar de compatibilitate care permite execuția nativă a aplicațiilor macOS pe Linux.

Un mediu grafic nou: Wayland, Skia și aplicații native

Noua arhitectură desktop renunță la vechile baze și introduce un ecosistem complet rescris:

  • Compozitor Wayland dedicat: Dezvoltat direct de echipă, acesta gestionează shell-ul desktop-ului, ferestrele, animațiile fluide și efectele vizuale de blur și transparență.

  • Toolkit C++ cu randare Skia: Interfața folosește un set nativ de unelte grafice în C++ randate prin intermediul bibliotecii Skia.

  • Suita de aplicații de bază: Desktop-ul vine echipat cu propriile programe integrate armonios vizual: manager de fișiere, emulator de terminal, panou de setări, calendar, monitor de sistem, editor de text, player video și un utilitar pentru capturi de ecran.

Proiectul „Reef”: Rularea aplicațiilor macOS nemodificate pe Linux

Cel mai surprinzător element tehnic al revenirii Cutefish este stratul de compatibilitate denumit Reef, conceput să execute aplicații macOS fără modificări.

Spre deosebire de o mașină virtuală sau un emulator clasic:

  • Fără emulare de procesor: Codul aplicațiilor rulează direct pe CPU, la viteza nativă a mașinii gazdă.

  • Reimplementarea framework-urilor: Reef oferă un încărcător de binare executabile Mach-O, un mediu de execuție Objective-C, suport pentru Swift și reimplementări pentru peste 80 de framework-uri macOS, inclusiv AppKit, Foundation și SwiftUI.

  • Grafică și stocare: Include integrare pentru WebKit, suport pentru baza de date Core Data și o implementare a API-ului grafic Metal transpus pe OpenGL.

Echipa a demonstrat funcționarea cu succes a cititorului de fluxuri RSS NetNewsWire (inclusiv bara laterală, vizualizarea articolelor, uneltele și gestionarea feed-urilor), alături de alte programe macOS cunoscute precum Ghostty, CotEditor, utilitarul de arhivare Keka și Ookla Speedtest.

Stratul Reef conține aproximativ 460.000 de linii de cod proprietar. Spre deosebire de mediul desktop Cutefish (care este open-source), Reef nu este în prezent open-source, fiind încă în stadiu experimental, fără o dată de lansare publică stabilită.

Integrare nativă pentru agenți AI (MCP)

Cutefish integrează suport pentru agenți inteligenți prin protocolul MCP (Model Context Protocol). Cu acordul explicit al utilizatorului, instrumente precum Claude Code sau Codex pot:

  • Vizualiza ecranul în timp real;

  • Executa acțiuni automate de tip click și tastare direct pe desktop.

Pentru siguranță, sistemul oferă un buton vizual de oprire imediată (stop control) și pune automat pe pauză acțiunile agentului în momentul în care utilizatorul atinge mouse-ul sau tastatura.

Disponibilitate: Imagini Debian 13 (Trixie)

Dezvoltatorii pun la dispoziție imagini de testare Cutefish 1.0 Nightly ISO bazate pe Debian 13 (Trixie), compatibile cu arhitecturile AMD64 și ARM64. Pentru cei care rulează deja o instalare existentă de Debian 13, pachetele mediului desktop pot fi instalate direct dintr-un depozit APT dedicat.

Atenție: Cutefish 1.0 nu a atins încă stadiul unei lansări stabile, imaginile actuale fiind versiuni de dezvoltare destinate exclusiv testării.
