plMail: Clientul de email self-hosted pentru Linux cu calendar sincronizat și inteligență artificială 100% locală

Gestionarea mai multor adrese de email fără a ceda controlul datelor către interfețe terțe reprezintă o provocare continuă pentru utilizatorii pasionați de self-hosting. plMail este un proiect open-source proiectat pentru a funcționa ca o platformă unificată de comunicații web, rulată direct pe propriul server Linux sau NAS și accesibilă din orice browser.

Ce este plMail (și ce nu este)

Pentru a evita confuziile legate de infrastructura de mail, dezvoltatorii clarifică din start rolul aplicației:

  • Nu este un server MTA: plMail nu găzduiește domenii de sine stătătoare și nu primește direct emailuri din internet (nu înlocuiește Postfix sau Mailcow).

  • Este un web client agregator avansat: Se conectează la conturile de email deja existente (IMAP standard, Gmail și Microsoft Outlook) și le sincronizează mesajele într-o bază de date locală PostgreSQL.

  • Inbox Unificat & Reziliență: Riunește toate adresele într-o singură căsuță poștală partajată, oferind căutare centralizată, etichete, dosare comune și suport pentru alias-uri de trimitere. Datorită copiei locale din PostgreSQL, mesajele deja sincronizate pot fi consultate chiar dacă serviciul furnizorului este temporar indisponibil.

Actualizările în timp real folosesc protocolul IMAP IDLE, mecanismele oficiale de push notification de la Google și Microsoft, alături de notificări native în browser. Pentru securitate, credențialele sunt stocate criptat în baza de date, accesul fiind protejat prin 2FA (autentificare în doi pași) și parole specifice de aplicație JMAP.

Calendar bidirecțional și integrări cu ecosistemul Self-Hosted

Pe lângă mesagerie, plMail include un modul complet de calendar cu sincronizare în dublu sens prin Google Calendar, Microsoft și protocoale CalDAV. Interfața săptămânală suportă rearanjarea evenimentelor prin drag-and-drop, gestionarea invitațiilor și unelte pentru programarea rezervărilor.

În plus, platforma se integrează nativ cu serviciile populare de stocare pentru atașamente și arhivare:

  • Cloud comercial: Google Drive, OneDrive, Dropbox

  • Servicii private / self-hosted: Nextcloud, Immich, Paperless-ngx

Inteligență artificială locală prin Ollama (Opțională și privată)

Una dintre cele mai moderne funcții din plMail este integrarea cu modele mari de limbaj (LLM), cu accent strict pe confidențialitate:

Caracteristică AIMod de funcționare
Integrare OllamaFuncțiile AI sunt complet dezactivate implicit. Utilizatorul poate conecta o instanță Ollama din rețeaua proprie.
Fără date în cloudNiciun email nu părăsește rețeaua locală; procesarea se face exclusiv pe hardware-ul utilizatorului.
Capabilități modularePot fi activate individual: căutare semantică, ciorne automate de răspuns, rezumatul conversațiilor lungi și auto-clasificarea mesajelor.
Căutare hibridăRezultatele semantice oferite de AI sunt evidențiate distinct față de căutările textuale exacte (from:, subject:, has:, before:), evitând confuziile.

Ghid de instalare rapidă cu Docker Compose

Aplicația este optimizată pentru rulare în containere pe arhitecturi linux/amd64 și linux/arm64 (servere dedicate, Raspberry Pi, NAS-uri sau VM-uri WSL2/macOS).

Pentru instalare pe un server Linux cu Docker și Docker Compose configurate:

Bash
git clone https://github.com/karatektus/pl_mail.git
cd pl_mail
sudo docker compose up -d

La prima pornire, serviciul generează automat cheile criptografice și secretele inițiale. Interfața devine accesibilă prin browser la https://localhost (sau adresa IP locală a serverului). Panoul inițial ghidează setarea domeniului, configurarea certificatelor TLS și conectarea primelor conturi prin OAuth2 sau credențiale IMAP.
