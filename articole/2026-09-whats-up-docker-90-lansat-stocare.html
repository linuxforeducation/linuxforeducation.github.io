What's Up Docker? 9.0 lansat: Stocare SQLite, control RBAC și token-uri de API

A fost lansată versiunea majoră What's Up Docker? 9.0 (WUD), popularul instrument open-source destinat monitorizării containerelor Docker și notificării automate atunci când sunt disponibile versiuni noi de imagini. Această actualizare aduce schimbări fundamentale de arhitectură, transformând WUD dintr-un simplu utilitar de notificare într-o platformă mai robustă și securizată pentru mediile de producție și homelab-uri.

Principalele noutăți din What's Up Docker 9.0

  • Stocare persistentă pe bază de SQLite: WUD renunță la stocarea stării în memorie/fișiere simple în favoarea unei baze de date SQLite. Aceasta asigură o persistență mult mai fiabilă a datelor, o pornire mai rapidă și posibilitatea de a istorisi eficient modificările containerelor.

  • Control al accesului bazat pe roluri (RBAC): Introduce un sistem nativ de permisiuni și autentificare (Role-Based Access Control), permițând administratorilor să definească utilizatori cu drepturi diferite (ex. vizualizare vs. administrare).

  • Token-uri de API securizate: Integrările cu alte aplicații sau scripturi terțe se pot realiza acum în siguranță prin intermediul API tokens, fără a mai fi necesară expunerea credențialelor principale.

  • Interfață Web actualizată: UI-ul a primit optimizări vizuale și de performanță pentru a reflecta noile opțiuni de gestionare a utilizatorilor, token-urilor și istoricului de actualizări.

Despre What's Up Docker (WUD)

Spre deosebire de instrumente precum Watchtower (care pot actualiza automat containerele imediat ce apare o imagine nouă), WUD se concentrează pe notificări inteligente și control manual, oferind integrări vaste:

CaracteristicăDetalii
Canale de NotificareSuport pentru Discord, Telegram, Slack, Gotify, Email, Webhooks, Home Assistant etc.
Monitoare de RegiștriMonitorizează Docker Hub, GitHub Container Registry (GHCR), GitLab, Quay, Harbor etc.
Securitate & ControlPermite filtrarea containerelor prin etichete (labels) și declanșarea de declanșatori (triggers) personalizați.
