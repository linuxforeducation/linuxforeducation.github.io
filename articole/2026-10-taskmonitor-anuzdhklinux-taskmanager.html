TaskMonitor (anuzdhk/linux-taskmanager): Depozitul GitHub oficial al managerului de activități în stil Windows Task Manager, construit în Rust și Slint

Depozitul GitHub anuzdhk/linux-taskmanager găzduiește codul sursă oficial al aplicației TaskMonitor (cunoscută și ca Linux Task Manager), dezvoltată de echipa Little Systems / anuzdhk sub licența permisivă MIT.

Proiectul a fost conceput ca un răspuns direct pentru utilizatorii Linux care caută o alternativă nativă, completă și ergonomică la celebrul Windows Task Manager (taskmgr.exe), reunind procesele, graficele hardware în timp real, serviciile de sistem, aplicațiile la pornire și managementul utilizatorilor într-o interfață modernă bazată pe carduri.

Arhitectura tehnică: Rust, Slint și amprentă minimă de resurse

Spre deosebire de aplicațiile construite pe framework-uri greoaie bazate pe Electron/Chromium, TaskMonitor adoptă o stivă nativă de înaltă eficiență:

  • Nucleu în Rust: Asigură siguranța memoriei, execuție rapidă și latențe minime la interogarea arborelui de procese.

  • Toolkit grafic Slint: Utilizează Slint pentru o randare grafică fluidă și declarativă, rezultând un consum mediu de doar 1–2% dintr-un singur nucleu CPU și aproximativ ~35 MB RAM.

  • Zero treziri inutile pentru GPU (dGPU Friendly): Monitorizarea plăcilor video dedicate de pe laptopuri este optimizată special pentru a nu scoate procesorul grafic (NVIDIA/AMD) din starea de repaus profund (sleep/d3cold), protejând autonomia bateriei pe computerele portabile.

Structura pe secțiuni și capabilități cheie

TaskMonitor mapează funcționalitățile esențiale din Windows Task Manager direct pe subsistemele Linux:

SecțiuneFuncționalități și Comportament
01. Processes (Procese)Separare clară între aplicații de prim-plan, procese din fundal și componente de sistem. Grupuri expandabile, afișaj cromatic tip heat-map, căutare instantanee și sortare după consum de CPU, RAM, disc și GPU.
02. Performance (Performanță)Grafice live pentru CPU (încărcare totală și granular per fir/thread), memorie, fiecare disc și adaptor de rețea. Monitorizare GPU pentru Intel și AMD prin kernel, iar pentru NVIDIA prin biblioteca NVML.
03. Process ActionsÎnchidere clasică (End Task / SIGTERM), forțare (Kill / SIGKILL), suspendare (SIGSTOP), reluare (SIGCONT), terminarea întregului arbore (End process tree), Efficiency mode, prioritate (nice), afinitate CPU (affinity) și lansarea de activități noi (Run new task). Acțiunile pe procesele altor utilizatori sau root sunt autorizate prin polkit.
04. Services (Servicii systemd)Vizualizarea stării serviciilor systemd la nivel de sistem și utilizator, cu opțiuni de pornire, oprire, repornire, activare (enable) și dezactivare (disable).
05. Startup AppsActivarea și dezactivarea printr-un singur clic a intrărilor de autostart (fișiere .desktop).
06. Users (Utilizatori)Sesiuni active conectate cu indicarea consumului per utilizator de CPU și memorie; opțiuni de blocare (lock) sau deconectare (sign out).
07. Details & PropertiesListă completă a tuturor proceselor (inclusiv thread-urile de kernel), PID, utilizator proprietar, statistici de citire/scriere pe disc, număr de thread-uri, valoare nice și comanda completă de lansare.
08. App HistoryColectare locală și strict opțională (opt-in) a timpului de utilizare agregat pentru CPU, disc și GPU per aplicație (datele nu părăsesc niciodată calculatorul).
09. Top-bar StatsStatistică live în panoul de sistem/tray: afișată text lângă iconiță pe GNOME, sau la trecerea cursorului (hover) pe KDE Plasma.

Instalare și compatibilitate

TaskMonitor este compatibil cu orice distribuție Linux x86_64 lansată din 2018 până în prezent (care include glibc 2.28 sau mai nouă):

  • Ubuntu / Debian / Linux Mint / Pop!_OS:

    Bash
    sudo apt install ./taskmonitor_*.deb

  • Fedora / openSUSE / RHEL:

    Bash
    sudo dnf install ./taskmonitor-*.rpm

  • Arch Linux / Manjaro / EndeavourOS (AUR): Disponibil prin fișierul PKGBUILD dedicat din depozitul oficial (packaging/aur/PKGBUILD):

    Bash
    makepkg -si

  • Pachet universal AppImage:

    Bash
    chmod +x TaskMonitor-*.AppImage && ./TaskMonitor-*.AppImage

    (Notă: acțiunile administrative elevate prin polkit nu pot fi executate direct din containerul AppImage; pentru control administrativ complet se recomandă instalarea pachetelor native DEB, RPM sau din AUR).
