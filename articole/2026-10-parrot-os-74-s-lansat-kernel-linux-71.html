Parrot OS 7.4 s-a lansat: Kernel Linux 7.1, AnonSurf 6.0 și securitate consolidată

Echipa din spatele proiectului Parrot Security a lansat oficial versiunea Parrot OS 7.4, o actualizare importantă pentru distribuția populară axată pe securitate cibernetică, audit, testare de penetrare (pentesting) și protecția confidențialității.

Bazată pe ramura stabilă Debian, noua versiune aduce o serie de actualizări critice la nivel de kernel, unelte anonime și pachete de analiză de securitate.

Principalele noutăți din Parrot OS 7.4

  1. Kernel Linux 7.1:

    • Sistemul trece la seria de kernel Linux 7.1, oferind suport extins pentru hardware modern, performanțe mai bune în gestionarea memoriei și compatibilitate îmbunătățită cu adaptoarele Wi-Fi utilizate în auditul rețelelor wireless (suport mai bun pentru modul monitor și injection).

  2. AnonSurf 6.0 (Noua versiune a utilitarului de anonimizare):

    • Utilitarul propriu al sistemului, AnonSurf — care redirecționează întregul trafic al sistemului prin rețeaua Tor și aplică reguli stricte de firewall (iptables/nftables) — a ajuns la versiunea 6.0.

    • Noua versiune aduce o interfață mai curată, comutare mai rapidă a nodurilor Tor, protecție sporită împotriva scurgerilor de DNS (DNS leak protection) și o integrare mai bună cu serviciile VPN secundare.

  3. Actualizarea suitei de testare de penetrare (Pentesting Tools):

    • Toate uneltele majore preinstalate au fost aduse la zi: Metasploit, Nmap, Wireshark, Burp Suite, Aircrack-ng, SQLmap și John the Ripper.

    • S-au adăugat scenarii și scripturi noi pentru auditarea mediilor Cloud și a infrastructurilor de containere (Docker/Kubernetes).

  4. Mediul Desktop și Experiența Utilizatorului:

    • Ediția principală folosește un mediu desktop MATE / XFCE puternic personalizat, optimizat pentru consum redus de resurse.

    • Aplicațiile de utilizare zilnică (browserul securizat, clientul de e-mail, editoarele de text) au primit, de asemenea, patch-uri de securitate la zi.

Versiuni și ediții disponibile

Parrot OS 7.4 este oferit în mai multe variante specializate:

  • Security Edition: Ediția completă ce include toate uneltele de pentesting și analiză forensică.

  • Home/Workstation Edition: O versiune mai ușoară concepută pentru utilizare zilnică, confidențialitate și dezvoltare software.

  • Architect / Cloud / IoT: Imagini dedicate pentru instalări minimale, servere sau plăci de dezvoltare (cum ar fi Raspberry Pi).

Cum se face actualizarea?

Pentru utilizatorii care folosesc deja o versiune anterioară din seria Parrot OS 7.x, actualizarea se poate realiza direct din terminal, fără a fi necesară o reinstalare completă:

Bash
sudo parrot-upgrade

sau folosind comanda standard:

Bash
sudo apt update && sudo apt full-upgrade -y

Pentru instalări noi, imaginile ISO oficiale pot fi descărcate gratuit de pe site-ul proiectului (parrotsec.org).
