Fedora 45 Beta a fost lansat cu Linux 7.2, GNOME 51 și KDE Plasma 6.7


Fedora 45 Beta, programat pentru lansarea finală la sfârșitul lui octombrie, este acum disponibil pentru testare. Această versiune aduce o previzualizare a ceea ce ne așteaptă de la următoarea lansare majoră a distribuției.

🔹 Ce noutăți aduce Fedora 45 Beta?

✅ Kernel și medii desktop:

  • Kernel Linux 7.2.
  • Fedora Workstation include GNOME 51.
  • Fedora KDE Plasma Desktop vine cu KDE Plasma 6.7.

✅ Schimbări majore la consola sistemului:

  • Trecere de la vechea consola fbcon din kernel la kmscon, o consola în spațiul utilizator care ofera:
    • Gestionare îmbunătățită a fonturilor și Unicode.
    • Randare modernă.

✅ Gestionarea semnăturilor pachetelor RPM:

  • Verificarea semnăturilor este acum impusă implicit.
  • Pachetele RPM nesemnate sunt respinse decât dacă utilizatorul dezactivează explicit această verificare.

✅ Îmbunătățiri ale installer-ului (Anaconda):

  • Suport pentru partitionare Stratis, inclusiv:
    • Configurare manuală prin interfața web.
    • Instalare automatizată prin Kickstart.
  • Fedora Atomic Desktops avansează către installer-ul web Anaconda.
    • Imaginile ISO sunt construite cu image-builder.
    • Fedora lucrează la fluxuri de instalare specializate pentru variantele Atomic.

✅ Fedora CoreOS:

  • systemd-oomd și zram swap sunt acum activate implicit, ceea ce schimbă modul în care sistemul gestionează presiunea asupra memoriei și swap-ul.

✅ Schimbări în managerul de pachete DNF5:

  • Nu mai comută automat un pachet instalat de la un furnizor la altul în timpul actualizărilor sau rezolvării dependențelor.

✅ Stack-ul de dezvoltare actualizat:

  • GCC 16.2
  • glibc 2.44
  • Go 1.27
  • LLVM 23
  • Perl 5.44
  • Python 3.15

✅ Disponibilitate:

  • Fedora 45 Beta este disponibil pentru:
    • Workstation
    • KDE Plasma Desktop
    • Server
    • Cloud
    • IoT
    • Atomic Desktops
    • Spins
    • Labs
  • Unele imagini individuale nu sunt incluse în beta, cum ar fi MiracleWM, Budgie Atomic și Sway Atomic.

✅ Fedora Linux Asahi Remix 45 Beta:

  • Disponibil pentru Mac-uri cu Apple Silicon.
  • Primul release cu suport inițial "out-of-the-box" pentru sistemele Apple M3, M3 Pro și M3 Max.
  • Accelerația 3D pe hardware M3 nu este încă gata și va veni mai târziu printr-o actualizare Mesa.
  • Decodarea video hardware-accelerată H.264 și VP9 este suportată pe toate Mac-urile cu Apple Silicon.
  • Decodarea AV1 este disponibilă pe sistemele M3.

⚠️ Atenție: Aceasta este încă o versiune beta, destinată în principal testării și raportării de bug-uri, nu pentru utilizare în producție.
