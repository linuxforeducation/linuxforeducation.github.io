OpenPencil (openpencil.dev): Alternativa open-source și AI-native la Figma, compatibilă direct cu fișierele .fig

În peisajul uneltelor de design de interfață (UI/UX), monopolul platformei Figma a transformat fișierele de design în formate binare proprietare legate indisolubil de cloud-ul unui singur furnizor. OpenPencil este un editor de design vectorial modern, 100% open-source (sub licență permisivă MIT), conceput pe o premisă arhitecturală opusă: un design este un arbore de noduri programabil (Design-as-Code), nu doar o simplă imagine stocată pe servere externe.

Aplicația rulează complet local-first pe desktop (Linux, macOS, Windows) sau în browser, este compatibilă nativ la nivel binar cu fișierele .fig și integrează agenți de inteligență artificială direct pe pânza de lucru (canvas) prin protocolul deschis MCP (Model Context Protocol).

Compatibilitate nativă bidirecțională cu Figma (.fig)

Cea mai mare barieră în migrarea de pe Figma a fost întotdeauna blocarea formatului. OpenPencil rezolvă această problemă printr-un motor intern de decodare și encodare:

  • Import și export .fig complet: Citește direct fișiere .fig — paginile, componentele, instanțele, variabilele de design și cadrele cu Auto Layout devin straturi vectoriale editabile și pot fi salvate înapoi în format .fig fără a rupe legăturile cu librăriile externe.

  • Import HTML, CSS și SVG: Inserarea de cod HTML sau SVG este convertită automat în noduri de design structurate conform regulilor de layout ale unui browser web real.

  • Fills animate prin Shadere: Permite aplicarea shaderelor GLSL/WASM ca umpleri de straturi (compatibile cu preseturi de pe shaders.com), păstrând o captură statică pentru compatibilitatea cu uneltele clasice și permițând redare animată în modul Preview.

Arhitectură AI-Native și colaborare prin MCP (Model Context Protocol)

Spre deosebire de uneltele grafice care adaugă doar un chat generic lateral, OpenPencil este proiectat pentru a fi operat direct de agenți software autonomi:

  • Server MCP încorporat (122 de unelte): Expune un server MCP (prin stdio sau HTTP la 127.0.0.1:7600/mcp) cu peste 120 de instrumente prin care agenți precum Claude Code, Cursor, Windsurf, Codex sau Gemini CLI pot citi structura arborelui grafic, crea straturi, mapa stiluri sau extrage tokeni.

  • Editare prin limbaj natural cu streaming vizual: Utilizatorul descrie modificarea dorită, iar agentul manipulează componentele pe pânză în timp real, cu animații fluide de tip Server-Sent Events (SSE).

  • Colaborare P2P fără server: Include colaborare în timp real prin WebRTC (fără conturi obligatorii), cu cursoare sincronizate, mod de urmărire a vizualizării (follow mode), comentarii atașate la straturi și apeluri vocale integrate.

De la Design la Cod: Reka UI, Radix și Storybook

OpenPencil elimină decalajul dintre designul vizual și implementarea de frontend:

DomeniuIntegrare în OpenPencil
Componente Interactive RealeAtribuirea de comportamente native de interfață (switch, checkbox, slider, tabs, text field) care rulează în modul Preview ca controale reale bazate pe librăriile Reka UI (pentru Vue) sau Radix UI (pentru React).
Generare de cod sincronizatăOrice selecție de pe canvas poate fi inspectată și exportată direct ca componente Vue, React, Tailwind CSS v4 sau JSX curat de design, legate bidirecțional (modificarea codului JSX actualizează canvasul).
Export StorybookGenerare automată de povești Storybook cu controale funcționale direct din variantele componentelor.
Design Tokens (W3C)Variabilele de culori, spațiere și tipografie cu moduri multiple sunt tratate ca tokeni standard W3C și exportate direct ca proprietăți CSS personalizate (var(--token)).
Linter integratDetectează în timp real erori de contrast, fonturi prea mici, straturi ascunse sau grupuri goale, oferind corectare automată cu un singur clic.

Ecosistem pentru dezvoltatori: CLI și SDK Headless

OpenPencil este gândit ca un set modular de biblioteci npm:

  • @open-pencil/core & @open-pencil/scene-graph: Motoarele de randare și reprezentare a arborelui grafic;

  • Headless Vue SDK: Permite încorporarea completă a unei suprafețe de desenare OpenPencil în orice aplicație web sau produs SaaS terț;

  • Binarul CLI (openpencil / op): Permite interogarea fișierelor de design prin sintaxă XPath, generarea de diff-uri vizuale, rularea de scripturi compatibile cu Figma Plugin API și conversii automate în pipeline-uri CI/CD:

    Bash
    # Interogare și linting headless fără interfață pornită
openpencil lint ./ui-kit.fig
openpencil export ./landing.fig --to png --output ./dist

Disponibilitate și instalare

  • Web: Disponibil direct în browser la app.openpencil.dev (nu necesită instalare; suportă WebGPU și CanvasKit WASM).

  • Linux: Pachete binare de sine stătătoare .AppImage, .deb (necesită WebKitGTK 2.40+) și opțiuni de pachet Nix pe arhitecturi x86_64.

  • macOS & Windows: Instalabil prin Homebrew (brew install --cask openpencil) sau Scoop (scoop install openpencil).
