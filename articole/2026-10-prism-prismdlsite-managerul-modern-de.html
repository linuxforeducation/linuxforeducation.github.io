Prism (prismdl.site): Managerul modern de descărcare open-source construit în Rust și Tauri — alternativă directă la Internet Download Manager (IDM)

În categoria utilitarelor desktop de accelerare a descărcărilor, soluțiile comerciale precum Internet Download Manager (IDM) au dominat mult timp piața Windows prin eficiența segmentării fișierelor și integrarea automată cu browserul. Pe Linux și macOS însă, utilizatorii au fost nevoiți adesea să apeleze la unelte CLI (cum ar fi aria2c), extensii fragile de browser sau aplicații greoaie bazate pe Electron.

Proiectul open-source Prism (lansat recent în versiunea 1.0 sub licența permisivă MIT) reprezintă o alternativă curată, concepută de la zero în Rust și Tauri. Acesta combină performanța brută a transferurilor multi-fir cu o interfață modernă, fluidă și axată pe confidențialitate totală (fără reclame, fără telemetrie și fără conturi necesare).

Arhitectură și performanță: Motor dinamic de conexiuni (Multi-Connection Engine)

Spre deosebire de descărcătoarele standard care asamblează bucățile descărcate abia la final (un proces lent de copiere I/O pe disc), Prism scrie datele direct în fișierul destinație prin scrieri poziționate (positioned writes):

  • Algoritm de furt de sarcină (Work-Stealing): Împarte fiecare descărcare în până la 32 de conexiuni paralele. În momentul în care o conexiune își termină segmentul alocat, aceasta preia automat jumătatea superioară din cel mai mare interval rămas activ, menținând toate firele de execuție ocupate până la ultimul octet.

  • Fără pas final de asamblare: Prin alocarea spațiului și scrierea directă pe segmente, un fișier de mari dimensiuni este gata instantaneu la finalizarea transferului, atingând în benchmark-uri viteze locale de peste 1000 MiB/s (de până la 3.2x mai rapid decât aria2c în transferuri neobstrucționate).

  • Adaptare la limitările serverului: Detectează automat serverele care restricționează numărul de conexiuni simultane sau aplică limitări per-IP, ajustând conexiunile pentru a evita erorile HTTP 429 sau 503.

  • Recuperare sigură la căderi (Crash-Safe Resume): Datele sunt sincronizate fizic pe disc înainte de salvarea metadatelor de progres. În caz de pană de curent sau repornire forțată, descărcarea este reluată pe baza headerelor ETag și Last-Modified, iar integritatea este validată prin sume SHA-256.

  • Protocoale suportate: HTTP/1.1, HTTP/2, FTP/FTPS, fluxuri adaptive HLS și DASH, plus suport nativ pentru fișiere .torrent și legături magnet:.

Integrare cu browserul și descărcare video (yt-dlp)

Prism rezolvă principalele scenarii zilnice întâlnite la utilizarea unui download manager modern:

Modul / FuncționalitateDetalii tehnice și comportament
Preluare automată a descărcărilorPrintr-un helper nativ (Native Messaging), extensia de browser transmite linkul către Prism în aproximativ ~250 ms. Reguli configurabile filtrează preluarea după tip MIME sau dimensiune (tasta Alt permite descărcarea clasică prin browser).
Păstrarea sesiunilor și cookie-urilorPentru fișierele protejate prin autentificare pe forumuri sau platforme cloud, cookie-urile necesare sunt trimise exclusiv către instanța locală a aplicației, fără a părăsi calculatorul.
Descărcare video până la 8K HDRButon direct de descărcare suprapus peste playerele video din peste 1.000 de platforme (YouTube, Vimeo, Twitch, Reddit, X etc.). Prism gestionează, verifică prin SHA-256 și actualizează automat dependențele yt-dlp, ffmpeg și deno.
Planificator & Cozi (Queues & Scheduler)Cozi multiple de descărcare cu priorități, limite orare de lățime de bandă și acțiuni automate la finalizare (oprire sistem, sleep sau rularea unui script de sistem).
Site GrabberModul de scanare recursivă a paginilor web pentru extragerea în lot a galeriilor foto, cărților (PDF/EPUB) sau documentațiilor tehnice.

Disponibilitate și instalare pe Linux

Datorită bazei tehnologice Tauri (backend Rust cu interfață grafică nativă prin WebKitGTK), pachetele de instalare sunt foarte compacte (~17 MB) comparativ cu aplicațiile Electron clasice:

  • Debian / Ubuntu / Linux Mint:

    Bash
    sudo apt install ./Prism_1.0.8_amd64.deb

  • Fedora / openSUSE / RHEL:

    Bash
    sudo dnf install ./Prism-1.0.8-1.x86_64.rpm
# pe openSUSE:
sudo zypper install ./Prism-1.0.8-1.x86_64.rpm

  • Pachet universal AppImage: Disponibil pentru orice altă distribuție (Prism_1.0.8_amd64.AppImage).

  • Integrare extensie: Extensiile oficiale sunt disponibile pentru browserele bazate pe Chromium (Chrome, Brave, Edge, Opera, Vivaldi) și Mozilla Firefox.
