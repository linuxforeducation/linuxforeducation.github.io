Fundația The Document Foundation (TDF) a publicat date statistice impresionante privind adopția celei mai recente versiuni majore a suitei sale office. Lansarea versiunii LibreOffice 26.8 a declanșat un val masiv de interes, descărcările săptămânale depășind constant pragul de un milion de unități.

În intervalul de opt săptămâni cuprins între 24 august și 18 octombrie, suita a acumulat un total de peste 9,4 milioane de descărcări directe.

Cifrele din spatele succesului

Datele de trafic agregate prin platforma analitică open-source Matomo subliniază amploarea utilizării suitei la nivel global:

  • 9,4 milioane de descărcări directe pentru versiunea curentă;

  • 11.426.169 de vizite pe portalul dedicat de descărcare;

  • 90.042.601 de vizite / interogări pe serverele destinate actualizărilor de sistem;

  • 39.669.854 de vizite pe paginile care găzduiesc versiuni moștenite (legacy / older versions).

Notă metodologică: Numărul de descărcări nu include pachetele de actualizare automată distribuite către utilizatorii existenți de Windows și nici instalările din arhivele versiunilor mai vechi, ceea ce înseamnă că baza reală de instalări active este considerabil mai mare.

Factorii cheie: Suveranitate digitală și rezistență la presiunile pieței

Într-un comentariu semnat de Italo Vignoli, The Document Foundation pune această creștere pe seama a două direcții strategice pe care proiectul le-a urmat constant:

  1. Promovarea suveranității digitale și a standardelor deschise: Tot mai multe organizații, administrații publice și utilizatori individuali conștientizează riscurile de dependență (vendor lock-in) față de abonamentele cloud comerciale și preferă să dețină controlul complet asupra propriilor documente prin formatul Open Document Format (ODF).

  2. O identitate proprie, fără compromisuri: Spre deosebire de alte produse care încearcă să cloneze în detaliu interfața sau deciziile comerciale din Microsoft 365, LibreOffice și-a păstrat propria viziune — prioritizând robustețea, tipografia profesională, compatibilitatea extinsă și absența funcțiilor intruzive nesolicitate.

Fundația Apache Software Foundation a publicat notele de lansare pentru Apache OpenOffice (AOO) 4.1.17, o versiune axată pe securitate, rezolvarea de erori și rafinări funcționale. Echipa de dezvoltare recomandă tuturor utilizatorilor aflați pe versiunea 4.1.16 sau anterioare să efectueze upgrade-ul la noua ediție.

Aplicația este disponibilă oficial pentru descărcare pe site-ul de proiect (openoffice.org), urmând să fie distribuită în curând și prin Microsoft Store pentru utilizatorii de Windows 10 și 11. La instalare, versiunea poate fi verificată în fereastra Help - About, unde trebuie să figureze șirul de identificare: AOO4117m2 | Build ID 9818 | Rev. 49c05bc6fd.

Cele mai importante îmbunătățiri și noutăți

Deși suita se concentrează pe stabilitatea liniei 4.1.x, versiunea 4.1.17 aduce câteva adiții tehnice notabile:

  • Macrocomenzi Python extinse: Scripturile Python pot fi acum create, editate, rulate și integrate (embedded) direct în interiorul documentelor.

  • Salvare mai sigură a fișierelor (Atomic Save): Documentele sunt scrise și înlocuite atomic pe disc, reducând semnificativ riscul de corupere a fișierelor în timpul opririlor bruște ale PC-ului sau al întreruperilor de sistem în timpul salvării.

  • Compatibilitate sporită cu formatele CAD și Office: Importul fișierelor DXF a fost extins pentru a randa mai corect primitivele de desen, iar compatibilitatea cu documentele Microsoft Excel XML (inclusiv conversia formulelor SpreadsheetML) și fișierele ODF/XML a devenit considerabil mai fiabilă.

  • Baze de date și interfață: Suport îmbunătățit pentru baze de date, cursoare noi de mouse și stabilirea monedei Euro ca monedă implicită pentru regiunea Bulgaria.

Corecții critice și stabilitate pe platforme

Pe lângă protecția la scrierea pe disc, au fost remediate erori structurale de runtime:

  • Windows: Tratarea corectă a parametrilor invalizi raportați de biblioteca de runtime Win32.

  • macOS: Stabilitate crescută la nivel de runtime și remedierea verificatorului automat de actualizări (update check).

  • Dicționare și localizare: Au fost actualizate traducerile în limba germană și dicționarele ortografice pentru engleză (SUA, Marea Britanie, Australia, Canada, Africa de Sud) și daneză.

Suport pentru platforme și probleme cunoscute

OpenOffice 4.1.17 continuă să asigure pachete oficiale pe 32 și 64 de biți pentru Windows, macOS și Linux (formate DEB și RPM).

Dezvoltatorii reamintesc utilizatorilor două detalii tehnice importante legate de dependența Java:

  1. Pe Windows: OpenOffice continuă să necesite un mediu Java Runtime Environment (JRE) pe 32 de biți, chiar dacă este instalat pe o versiune de Windows pe 64 de biți. Dacă sistemul semnalează că Java este defectuos, se recomandă instalarea pachetului redistribuibil Microsoft Visual C++ 2015–2019.

  2. Pe macOS: Dintr-o problemă cunoscută de compatibilitate din Oracle Java, recunoașterea versiunilor moderne de Java poate necesita instalarea pachetului moștenit Apple Java 6 dacă nu se utilizează versiuni compatibile precum Java 9.
